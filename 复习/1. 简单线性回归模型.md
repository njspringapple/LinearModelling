
- **模型定义**：$Y_i=\beta_0+\beta_1x_i+\varepsilon_i,\quad i=1,\dots,n$
	- **误差说明**：
		- $E(\varepsilon_i)=0$
		- $V(\varepsilon_i)=\sigma^2$
	- **条件均值**：
		- $E(Y_i\mid x_i)=\beta_0+\beta_1x_i$
	- **假设 $x_i$ 和 $Y_i$ 有线性关系**，称
		- $Y_i$: 目标变量 / Zielgroesse
		- $x_i$: 解释变量 / Einflussgroesse
	- $\varepsilon_i$: **随机误差** / Zufallsfehler，不可观测 （ **采集时候的各种误差** ）
	- $\beta_0,\beta_1,\sigma^2$: 未知参数 / unbekannte Parameter （**要求解的模型参数**）
	- $\widehat{\varepsilon}_i$: **残差** / Residuum，根据计算得到的参数，代入 $x_i$ 后得到的 $\hat{Y}_i$，和实际采集到的 $Y_i$ 之间的误差：$\widehat{\varepsilon}_i = \hat{Y}_i - Y_i$，也可以写为 $\widehat{\varepsilon}_i=Y_i-\widehat{\beta}_0-\widehat{\beta}_1x_i$
		- 这里 $\hat{\beta}_0, \hat{\beta}_1$ 为什么又 hat， 是因为 x 和 Y 的实际线性关系参数**我们无法知道**，只能**根据采样的数据**，通过算法（例如OLS二乘法）来**估计这两个参数**
	- **参数估计的方法**：
		- **最小二乘法（OLS）**：$(\widehat{\beta}_0,\widehat{\beta}_1)=\arg\min_{\beta_0,\beta_1}\sum_{i=1}^n (Y_i-\beta_0-\beta_1x_i)^2$
			- 左侧：估计的参数
			- 右侧：将采集到的 x 代入线性模型，得到的值和采集到的 Y 的差距的 **平方和最小** 的情况下，参数 $\beta_0,\beta_1$ 的取值。
			- 这里 $x_i, Y_i$ 是采集到的值，是已知条件，$\beta_0,\beta_1$ **是要求解的**
			- 使用平方和是因为：正负残差经过平方变成正数，不会相互抵消。但是也因为是平方，会对 “**离群点**” 的 “**惩罚**” 很重，**残差会被放大** ！！！！


- **参数求解方法**
	- **目标函数**：$Q(\beta_0, \beta_1) = \sum_{i=1}^n (Y_i-\beta_0-\beta_1x_i)^2$
	- 要求函数最小值，先做一阶偏导数 = 0， 解出得到 “**驻点**”
		- **线性函数的 截距**：$\frac{\partial Q}{\partial \beta1} = 0$，得到，$\hat{\beta_0} = \bar{Y} - \hat{\beta_1}\bar{x}$  
		- **线性函数的 斜率**：再对 $\frac{\partial Q}{\partial \beta_0} = 0$，得到，$\widehat{\beta}_1=\frac{\sum_{i=1}^n (x_i-\bar{x})(Y_i-\bar{Y})}{\sum_{i=1}^n (x_i-\bar{x})^2}$, **化简后是**：$\hat{\beta}_1 = Cov(x,Y)/Var(x)$  
		- **条件概率解释 斜率**：$E(Y\mid x+1)-E(Y\mid x)=\beta_1$   -- 在 x 每增加一个单位，Y **平均增加的值**


- **加入测量误差后**
	- 假设：$E(\varepsilon_i)=0$ ，$V(\varepsilon_i)=\sigma^2$ ，误差 i.i.d ，则：
		- $E(\widehat{\beta}_0)=\beta_0,\quad E(\widehat{\beta}_1)=\beta_1$
		- $Var(\widehat{\beta}_1)=\frac{\sigma^2}{\sum_{i=1}^n (x_i-\bar{x})^2}$
		- $Var(\widehat{\beta}_0)=\sigma^2\left(\frac{1}{n}+\frac{\bar{x}^2}{\sum_{i=1}^n (x_i-\bar{x})^2}\right)$
		- 误差方差（**测量噪声**）越大，方差越大，也就是拟合的**参数精准度不好，判定不准确**
		- **数据量**越大（n），方差越小（拟合的越精准，所以要大数据量）
	- $Y \sim N(\beta_0 + \beta_1x, \sigma^2)$


- **误差的方差（$\sigma^2$）的估计**
	- $\widehat{\sigma}^2=\frac{1}{n-2} \sum_{i=1}^n \widehat{\varepsilon}_i^2$  -- **自由度解释清楚**：简单线性回归估计了 $\beta_0$ 和 $\beta_1$ 两个参数，所以剩余自由度为 $n-2$
	- $E(\widehat{\sigma}^2)=\sigma^2$


- **置信区间**：对估计出来的参数 “**把握**” 有多大
	- fit <- lm(dist ~ speed, data = cars)
	- confint(fit) 
	- 用这个代码看拟合出来的斜率和截距的 **2.5% ~ 97.5%** （**正态分布中间**）的取值范围，例如在这个分布区间内的 speed的取值是 **【 3.096964， 4.767853】** 

- **平方和分解**：
	- SST（总偏差） = SSM（模型解释）+ SSE（残差变异）
		- SST：$\sum_{i=1}^n (Y_i-\bar{Y})^2$         -- 测量值 和 均值 差异（**Sum of Squares Total**）--------- 总差异
		- SSM：$\sum_{i=1}^n (Y_i-\widehat{Y}_i)^2$        -- 测量值 和 预测值 差异（**Sum of Squares Model**） ---- 模型差异
		- SSE：$\sum_{i=1}^n (\widehat{Y}_i-\bar{Y})^2$         -- 均值 和 预测值 差异 （**Sum of Squared Errors**）     ---- 线性回归模型没法解释的，越小越好
		- $R^2=\frac{SSM}{SST}=1-\frac{SSE}{SST}$   -- 模型能解释得差异部分占总差异得比例                            ---- 模型差异比例
		- **简单线性回归里面，$R^2 = r_{XY}^2$  -- 正好等于, 所以，$R^2 = 1$ 所有采集点都在回归的线上 $R^2 = 0.8$ 模型解释了80%的差异  $R^2 = 0$ 模型什么也没有解释**
			- 皮尔逊系数捕捉线性关系，所以皮尔逊系数为 0，说明用线性模型不能解释数据关联


- **预测和预测区间**：给定新解释变量值 $x_{n+1}$，我们想预测未来的 $Y_{n+1}$。点预测容易给出，但单个新观测还包含随机误差，因此需要区间
	- 只给 $\widehat{Y}_{n+1}$：**没有不确定性**
	- 给均值置信区间：回答 $E(Y\mid x_{n+1})$ 的范围
	- 给预测区间：回答未来单个 $Y_{n+1}$ 的可能范围
	- predict(fit, newdata = new_speed, interval = "**confidence**")
	- predict(fit, newdata = new_speed, interval = "**prediction**")  -- 预测的区间更宽，它还包含未来单个观测的随机误差
	- 先问问题对象是均值 $E(Y\mid x_{n+1})$ 还是未来个体 $Y_{n+1}$。如果是未来个体，用 `interval = "prediction"`；如果是均值，用 `interval = "confidence"`。

- **变换、线性近似与外推风险**：真实关系可能不是直线，线性模型有时只是局部近似
	- 所谓 **外推**，就是在采样数据以外（例如采集了x = 1-100 的数据，然后线性建模，再希望用建模结果预测 x = 1000 的 Y值）
	- 先画散点图和残差图
	- 如果看到弯曲（散点图连线弯曲），尝试加入 $x^2$ 或做变量变换
	- **若预测点远离观测范围，要明确标注外推风险（Extrapolation）**

- **模型假设检查的早期意识**：用最简单线性建模的约束条件
	- **同方差** / Homoskedastizitaet: $Var(\varepsilon_i)=\sigma^2$
		- **异方差** / Heteroskedastizitaet，即 $Var(\varepsilon_i)$ 不是常数
		- 例如，残差 Residuals 随着 拟合值 Fitted 增大而增大
	- 不相关 / unkorrelierte Fehler: $\operatorname{Cov}(\varepsilon_i,\varepsilon_j)=0$
	- **正态误差** / normalverteilte Fehler: $\varepsilon_i\sim N(0,\sigma^2)$
		- **Q-Q 图**，是否紧贴对角线，偏离对角线的点说明残差不是正态的
	- 线性均值 / Linearitaet: $E(Y_i\mid x_i)=\beta_0+\beta_1x_i$

- **Estimate** : 估计出的参数 $\hat{\beta}_0, \hat{\beta}_1$
- **Std. Error** ：标准误，估计的不确定性，**这里主要看斜率**， 如果标准误很小，说明不确定性很小，也就是估计的 “**很精准**”
- **t value**：t-分布的横坐标的值，t-分布式对称分布（看起来像正态），|t| 越大，两侧的 “**尾概率**” 越小 ( $P( |T| >= |t| ) = P( T >= |t|) + P( T <= -|t| )$ )  !!!! **双侧概率**
	- **原假设** $H_0$ ：原假设通常是「**没有效应、没有差异、没有关系**」的保守立场，所以，我们可以设 $H_0：\beta_1 = 0$ 
	- 在这个原假设情况下，看概率（满足 t-分布），即 $P(Data | H_0)$ ，**在原假设条件下，出现现有数据的概率是多少**
	- 显然，我们要看出心率对配速有影响，那就应该拒绝$H_0$，那 t 的绝对值应该大，进而下面的 p值应该小
