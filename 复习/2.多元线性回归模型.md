
- 最简单模型（一个自变量/解释变量）推广到多个自变量：   
	- **实际问题中，目标变量 $Y$ 往往同时受多个因素影响**
	- **建立多元线性回归**：同时控制多个变量，解释每个变量 **在其他变量固定时** 的边际作用
	- $Y_i=\beta_0+\beta_1x_{i1}+\beta_2x_{i2}+\dots+\beta_px_{ip}+\varepsilon_i,\quad i=1,\dots,n$ 
	- 改写为向量形式（**向量内积**） - **采集了对象的 p个维度的数据, $x_i$ 是第 i 组数据**
		- 设 $x_i^T = (1, x_{i1}, x_{i2}, ... , x_{ip})$，$\beta = (\beta_0, \beta_1, \beta_2, ... \beta_p)^T$
		- 则 $Y_i = x_i \cdot \beta + \epsilon_i$     -- 行向量 x 列向量就是内积操作，展开后就是上面的多元线性回归方程
		- 因为模型包含 截距，所以参数向量第一个元素为 1，代表 $\beta_0$ 

```r
data(mtcars)
fit <- lm(mpg ~ wt + hp + cyl, data = mtcars)

# **从拟合的模型对象中提取设计矩阵**
# 它返回模型实际用来做回归计算的那张**自变量矩阵**（也叫模型矩阵）
X <- model.matrix(fit)
# 想把 `mpg` 这一列的内容本身取出来（一个向量），而不是取出一个只含这一列的数据框
y <- mtcars[["mpg"]]

dim(X)
```

- **随机误差相关**
	- 符号：$\epsilon_i$ - 每行数据的误差          $\epsilon$ - n 个数据误差构成的误差向量( $(\epsilon_1, ... , \epsilon_n)^T$ )
	- 无偏：$E(\epsilon_i) = 0$  或者 $E(\epsilon) = 0$
	- 同方差：$Var(\epsilon_i) = \sigma^2$  或者 $Var(\epsilon) = \sigma^2 \cdot I$
	- $\epsilon \sim N(0, \sigma^2 \cdot I)$

```r
fit <- lm(mpg ~ wt + hp + cyl, data = mtcars)
```

- **最小二乘法估计**
	- **公式**：$\widehat{\beta}=\arg\min_{\beta}(Y-X\beta)^T(Y-X\beta)$
		- 解读：$Y - X\beta$ 就是选取一组拟合的参数 $\beta$ 使得总体数据的残差 $\sum e_i^2$ 最小，那这个 $\beta$ 就是估计出来的 $\hat{\beta}$
		- 线性代数相关：多元模型 $Y = X\beta$，确定 $\beta$ 后，$Y$ 和 $X\beta$ 之间总有差距，差距为 $Y - X\beta$ - **这是一个列向量，要求一眼看明白！！！**
	- **求解**：
		- **方案一**
			- $Y = X\beta$  看成线性变换 $Ax = b$
			- 因为 $X\beta$ 永远不可能等于 $Y$ ，即 $Y$ 不在 $X$ 的列空间 $Col(X)$ 上
			- 所以，Y 在列空间 $Col(X)$ 上的 ”**投影**“ 是最优解
			- 找到这个投影的方法是：两个向量的 ”**距离**“ - 也就是**残差**，**垂直于 X**
			- **正规方程**：即：$X^T\widehat{\varepsilon}=0 \Rightarrow X^T(Y - X\hat{\beta}) = 0 \Rightarrow \hat{\beta} = (X^TX)^{-1}X^TY$，这里有个前提是：$X^TX$ **要求可逆**
				- $X^T(Y - X\hat{\beta}) = 0 \Rightarrow X^TX \cdot \hat{\beta} = X^TY$   -- **Ax = b 的形式要能看懂！！**
				- 检查可逆的**等价方法**：（1）列满秩    （2）列线性无关     （3）正定（即 $x^TXx \ge 0$)      (4) $det(X^TX) \neq 0$

```r
data(mtcars)
fit <- lm(mpg ~ wt + hp + cyl, data = mtcars)

# 提取设计矩阵 X
X <- model.matrix(fit)
y <- mtcars[["mpg"]]

# 根据原理，手工计算，solve(A,b) 就是求解线性方程组的 x
beta_manual <- solve(t(X) %*% X, t(X) %*% y)
beta_lm <- coef(fit)

cbind(manual = as.vector(beta_manual),
      lm = beta_lm)

res <- y - X %*% beta_manual
# 检查是不是接近0
t(X) %*% res
```


- **产品矩阵**：$X^TX$
	- 因为要求可逆，所以 $X$ 满秩，所以 **rank(X) = p + 1** (p个特征参数，1个斜率)
	- 如果 `rank < columns` ，说明设计矩阵列线性相关，**至少有一个参数不能唯一估计**


- **$\hat{\beta}$ 的性质：**
	- $E(\hat{\beta}) = \beta$
	- $V(\widehat{\beta})=\sigma^2(X^TX)^{-1}$
	- 如果随机误差独立同分布，并且  $\varepsilon\sim N(0,\sigma^2I)$，那么：$\widehat{\beta}\sim N\left(\beta,\sigma^2(X^TX)^{-1}\right)$

- **帽子矩阵和残差向量：**
	- 因为 $\widehat{Y}=X\widehat{\beta}$，以及 $\hat{\beta} = (X^TX)^{-1}X^TY$
	- 所以，用估计的参数得到的拟合值：$\widehat{Y} = X(X^TX)^{-1}X^TY$
	- 我们设 $P = X(X^TX)^{-1}X^T$，则 $\widehat{Y} = PY$，那么称：**P或者H为帽子矩阵/投影矩阵**
	- 则残差 $\widehat{\varepsilon}$ = $Y - \hat{Y} = Y - PY = (I - P)Y$，设 $Q = I - P$，那么称：(I - P)为**残差矩阵**，则：$\widehat{\varepsilon} = QY$

- **直觉图像**
	- $X$ 的列向量张成模型空间 / Modellraum
	- $\widehat{Y}$ 是 $Y$ 投影到模型空间的点
	- $\widehat{\varepsilon}$ 是 $Y-\widehat{Y}$，与模型空间正交

- **帽子/投影矩阵性质**
	- **线性代数**：正交投影矩阵
		- **定义**：矩阵满足 $P^2 = P, P^T = P$ ，则称矩阵 P 为正交投影矩阵
		- **性质**：$tr(P) = rank(P)$
	- **对称**：$H^T = H$，$Q^T = Q$
	- **幂等**：$H^2 = H$, $Q^2 = Q$
	- **正交**：$PQ = 0$
	- $V(\widehat{Y})=\sigma^2P$
	- $V(\widehat{\varepsilon})=\sigma^2Q$
	- $tr(H) = rank(H)$，$tr(Q) = rank(Q)$

- **误差方差估计**
	- **问题**：$\sigma^2$ 是真实误差的方差，**但真实误差看不到**。我们只能用**残差平方和估计它**，并且必须扣除已经估计的参数个数
	- $\widehat{\sigma}^2=\frac{1}{n-(p+1)}\widehat{\varepsilon}^T\widehat{\varepsilon}=\frac{1}{n-(p+1)}\sum_{i=1}^n \widehat{\varepsilon}_i^2$    -- **注意两种书写方式等价，一个是平方求和，一个是向量内积**
	- $E(\widehat{\sigma}^2)=\sigma^2$   -- $\widehat{\sigma}^2$ **是对于误差方差的无偏估计**，$\sigma^2 = Var(\epsilon)$

```r
data(mtcars)
fit <- lm(mpg ~ wt + hp + cyl, data = mtcars)

rss <- sum(residuals(fit)^2)
# 提取残差自由度 n - p, 这个回归，三个参数（p） + 一个截距，如果数据集 32行，那自由度 = n - (p+1) = 32 - (3+1) = 28
df_res <- df.residual(fit)

c(sigma2_manual = rss / df_res,
  sigma2_lm = sigma(fit)^2,
  df_residual = df_res)
```


- **总结四个核心估计量**
	- **$\hat{\beta}$ 参数估计**
		- 估计：$\hat{\beta} = (X^TX)^{-1}X^TY$
		- 方差：$V(\widehat{\beta})=\sigma^2(X^TX)^{-1}$
	- **$\hat{Y}$ 拟合值**
		- 估计：$\hat{Y} = X\hat{\beta}$
		- 方差：$V(\widehat{Y})=\sigma^2H$
	- **$\widehat{\varepsilon}$ 残差**
		- 估计：$\widehat{\varepsilon} = Y - \hat{Y}$
		- 方差：$V(\widehat{\varepsilon})=\sigma^2Q$
	- **$\hat{\sigma}^2$ 误差方差**
		- 估计：$\widehat{\sigma}^2=\frac{1}{n-(p+1)}\widehat{\varepsilon}^T\widehat{\varepsilon}=\frac{1}{n-(p+1)}\sum_{i=1}^n \widehat{\varepsilon}_i^2$

- **总结四个矩阵**
	- 设计矩阵：就是采集的数据（**n个数据，每个数据 p 个特征量，包含截距**），写为
$$
X = 
\begin{pmatrix}
1 & x_{11} & x_{12} & \cdots & x_{1p} \\
1 & x_{21} & x_{22} & \cdots & x_{2p} \\
\vdots & \vdots & \vdots & \ddots & \vdots \\
1 & x_{n1} & x_{n2} & \cdots & x_{np}
\end{pmatrix}_{n \times (p+1)}
$$
	- 产品矩阵：$X^TX$，满秩
	- 帽子矩阵：$H = X(X^TX)^{-1}X^T$   ====>  $\widehat{Y} = HY$
	- 残差矩阵：$Q = I - P$  ====> $\widehat{\varepsilon} = QY$
	- **通过帽子矩阵，很快可以算出残差和拟合值**

- **和R语言函数映射**
	- $\widehat{\beta}\leftrightarrow \texttt{coef(fit)}$
	- $\widehat{Y}\leftrightarrow \texttt{fitted(fit)}$
	- $\widehat{\varepsilon}\leftrightarrow \texttt{residuals(fit)}$
	- $\widehat{\varepsilon}^T\widehat{\varepsilon}\leftrightarrow \texttt{deviance(fit)}$ -- **残差的平方和，称为 RSS（Residual Sum of Squares）**

练习 / Uebung: `hatvalues(fit)` 是哪个矩阵的对角线？  

答案 / Antwort: 它是 Hat-Matrix $P=X(X^TX)^{-1}X^T$ 的对角线。帽子矩阵的对角线 $h_{ii} =[H]_{ii}$ 也是每个观测的**杠杆值（Leverage）**

- **自由度和秩几个概念搞清楚**
	- 采集数据的特征（自变量）个数 - p
	- 参数个数 - (p+1)
	- 设计矩阵的秩 - rank(X)，正常是列满秩，严格写是 $rank(X) \leq (p + 1)$
	- 误差方差自由度：n - (p+1)

## 检查是否掌握

- 多元线性模型把简单线性回归扩展到多个解释变量：$Y_i=\beta_0+\beta_1x_{i1}+\dots+\beta_px_{ip}+\varepsilon_i$。
- 矩阵形式 $Y=X\beta+\varepsilon$ 是本章核心，$X$ 是设计矩阵，第一列通常对应截距。
- 多元模型中的 $\beta_k$ 表示在其他解释变量固定时，$x_k$ 增加一单位带来的条件均值平均变化。
- 最小二乘估计最小化 $(Y-X\beta)^T(Y-X\beta)$；若 $X^TX$ 可逆，则 $\widehat{\beta}=(X^TX)^{-1}X^TY$。
- 正规方程 $X^T\widehat{\varepsilon}=0$ 表示残差与设计矩阵每一列正交。
- Hat-Matrix $P=X(X^TX)^{-1}X^T$ 给出 $\widehat{Y}=PY$；Residualmatrix $Q=I-P$ 给出 $\widehat{\varepsilon}=QY$。
- $P$ 和 $Q$ 是投影矩阵，满足对称、幂等和互相正交。
- $\widehat{\sigma}^2=\frac{1}{n-(p+1)}\widehat{\varepsilon}^T\widehat{\varepsilon}$ 是 $\sigma^2$ 的无偏估计。
- full rank 是参数唯一估计的关键；若解释变量线性相关，会出现不可识别或软件删掉系数。
