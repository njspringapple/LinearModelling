
- 连续变量的交互作用：
	- 两个连续变量 $x_1, x_2$ **加上交互项**：$E(Y) = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 x_1 \cdot x_2$
	- **怎么理解**？两种等价视角
		- 固定 $x_1$，看 $x_2$ 的效果：$E(Y) = \underbrace{(\beta_0 + \beta_1 x_1)}_{\text{截距随 } x_1 \text{ 变}} + \underbrace{(\beta_2 + \beta_3 x_1)}_{\text{斜率随 } x_1 \text{ 变}} \cdot x_2$                 $x_2$ 对 $Y$ 的边际效应**不是常数**，而是 $\beta_2 + \beta_3 x_1$，取决于 $x_1$ 的值
		- 固定 $x_2$，看 $x_1$ 的效果：$E(Y) = (\beta_0 + \beta_2 x_2) + (\beta_1 + \beta_3 x_2) \cdot x_1$，              $x_1$ 对 $Y$ 的边际效应是 $\beta_1 + \beta_3 x_2$
		- **解释陷阱**
			- $\beta_1$ 的含义是"**当 $x_2 = 0$ 时**，$x_1$ 的斜率"。$\beta_2$ 同理是"**当 $x_1 = 0$ 时**，$x_2$ 的斜率"
			- 问题：$x_2 = 0$ 或 $x_1 = 0$ 往往没有实际意义！
			- **解决方案：中心化（Zentrierung）**
				- 将变量替换为 $\tilde{x}_1 = x_1 - \bar{x}_1$，$\tilde{x}_2 = x_2 - \bar{x}_2$。
				- 这样 $\beta_1$ 就是"当 $x_2$ 取**均值**时，$x_1$ 的斜率"——有意义得多！
- 连续型自变量的 8 种处理方式
	- **简单线性**：假设效应是一条直线，$E(Y) = \beta_0 + \beta_1 x$
	- **变量变换**：对 $x$ 做一个已知的变换 $T(\cdot)$，然后线性回归，$E(Y) = \beta_0 + \beta_1 T(x)$  -- 例如单位尺度变换，对数变换，$\beta_1$ 的解释**随变换而变**
	- **多项式回归**：用 $x$ 的幂次来拟合曲线，$E(Y) = \beta_0 + \beta_1 x + \beta_2 x^2 + \beta_3 x^3 + \cdots + \beta_k x^k$，**核心问题**：$k$ 选多大？实践中一般不超过 3 次或 4 次
	- **分段常数函数**：本质上就是把连续变量**分组/分箱（Kategorisierung）**，变成类别变量。**用途**：当 $x$ 只有少数几个取值时，可以用来**检验线性假设是否成立**。
		- $E(Y) = \begin{cases} \beta_0 & x \leq x_0 \\ \beta_1 & x_0 < x < x_1 \\ \vdots \\ \beta_h & x > x_{h-1} \end{cases}$
	- **分段线性函数**（Stückweise lineare Funktion）：整体是一条连续的折线，在每个断点处斜率可以改变。**场景：折线有拐角，例如 ：税率-》收税额，政策实施前后**
	![[Pasted image 20260923214638.png]]
	- **回归样条**（Regressionsspline）：基础部分 $\beta_0 + \beta_1 x + \beta_2 x^2 + \beta_3 x^3$ 是全局三次多项式。$E(Y) = \beta_0 + \beta_1 x + \beta_2 x^2 + \beta_3 x^3 + \beta_4 (x - g_1)^3_+ + \beta_5 (x - g_2)^3_+$
		- 每个断点处加一个 3 次项来局部调整形状，因为3次项二阶可微，曲线光滑，没有尖角
	![[Pasted image 20260923214726.png]]
	- **分数多项式**（Fraktionale Polynome）：不再局限于整数幂 $x, x^2, x^3, \ldots$，而是允许**分数幂和对数** ，$E(Y) = \beta_0 + \beta_1 x^{-2} + \beta_2 x^{-1} + \beta_3 x^{-0.5} + \beta_4 \ln(x) + \beta_5 x^{0.5} + \beta_6 x + \beta_7 x^2$
		- 标准的幂次集合为 $\{-2, -1, -0.5, 0, 0.5, 1, 2, 3\}$，其中 $x^0$ 约定为 $\ln(x)$
		- **非常灵活**，能拟合各种 U 形、J 形、**饱和型曲线**
	![[Pasted image 20260923214820.png|499]]
	- **三角多项式**（Trigonometrische Polynome）：用于建模**周期性/季节性**效应，$E(Y) = \beta_0 + \beta_1 \sin\!\left(\frac{2\pi}{T} x\right) + \beta_2 \cos\!\left(\frac{2\pi}{T} x\right) + \beta_3 \sin\!\left(\frac{2\pi}{T} \cdot 2x\right) + \beta_4 \cos\!\left(\frac{2\pi}{T} \cdot 2x\right)$
		- 其中 $T$ = 周期长度，$x$ = 时间
		- 预期是平滑周期变化使用三角多项式，例如冰淇淋销量随着季节周期变化，地铁客流，电商订单呢周末多工作日少！！
	![[Pasted image 20260923214905.png|470]]

- **通用基函数框架**
	- **统一视角**：上述所有方法都可以写成：$E(Y) = \beta_0 + \beta_1 B_1(x) + \beta_2 B_2(x) + \beta_3 B_3(x) + \cdots$
	- 其中 $B_1, B_2, B_3, \ldots$ 是**已知的基函数（Basisfunktionen）**
	- **关键领悟**：只要基函数是已知的，模型对**参数 $\beta$** 仍然是线性的！

| 方法 | 基函数 $B_j(x)$ |
|------|----------------|
| 简单线性 | $B_1(x) = x$ |
| 多项式 | $B_j(x) = x^j$ |
| 分段线性 | $B_1(x) = x,\; B_{j+1}(x) = (x - g_j)_+$ |
| 三次样条 | $x, x^2, x^3, (x-g_1)^3_+, (x-g_2)^3_+, \ldots$ |
| 三角多项式 | $\sin(\cdot), \cos(\cdot)$ |

- **多重检验与同时置信区间（Multiples Testen）**
	- **背景**
		- 在多元线性模型中，我们经常 **同时做多个检验或构建多个置信区间**
		- 建立的线性回归种有多个参数，我要检验药物A是否有效，药物B是否有效，年龄是否有效，这就是三次检验!!
		- 想一下，我们模型有20个参数，每个参数 p 值都很小，但是根据概率，20 个独立检验：P（至少一个错误拒绝）= $1 - (1-0.05)^20 = 0.64$
		- 意思是，不能认为20个参数都显著，都保留，**实际错误的概率是 64%**!!!!
		- 这就带来问题：检验越多，**犯错概率越高**！所以需要有矫正方法

| 概念                         | 定义                                       |
| -------------------------- | ---------------------------------------- |
| **局部水平（lokales Niveau）**   | 单个检验的显著性水平                               |
| **全局水平（globales Niveau）**  | 当**所有** $H_0$ 都成立时，至少拒绝一个的概率             |
| **多重水平（multiples Niveau）** | 至少**错误地**拒绝一个 $H_0$ 的概率 $< \alpha$（FWER） |

-  **四种常用策略**
	- **Bonferroni 校正**：做 $k$ 个检验时，每个检验用水平 $\alpha_l = \alpha / k$
		- **举例**：如果判定显著性的 $\alpha = 0.05$，有10个参数，那就把**显著性门限改为 0.05/10 = 0.005**
		- **缺点**：k 很大的时候，门限太小，**容易漏掉真效应**
	- **Scheffé 方法**
	- **Tukey / Hothorn et al. 方法（最大统计量）**
