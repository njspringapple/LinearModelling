

- **目的**：线性回归中（ $Y = X\beta + \varepsilon$ )，我们假设误差
	- $\varepsilon \sim N(0, \sigma^2)$
	- i.i.d
	- 我们需要检验这些假设对不对
	- 我们不知道真实的 **误差**，只有用 **残差** $\hat{\varepsilon} = Y - X\hat{\beta}$ 来代替
- **根据帽子矩阵定义**，$\hat{\varepsilon} = Y - \hat{Y} = (I - H)Y = QY$，$Var(\varepsilon) = \sigma^2Q$
	- $Var(\varepsilon)$ 是残差的协方差矩阵，**对角线是每个数据的残差的方差**
	- 这意味着，即使 $\varepsilon$ 全部 **等方差**，但是每个数据的残差的方差 $Var(\varepsilon)$ 也随着观察点不同而不同
	- **可以证明残差构成的协方差矩阵对角线中间最大，两头小**
- **标准化残差**：为了让残差可比较，除以它自己的标准差估计
	- $r_i := \frac{\hat{\varepsilon}_i}{\hat{\sigma}\sqrt{q_{ii}}}, \quad i = 1, \ldots, n$
	- $q_{ii} = 1 - h_{ii}$，$h_{ii}$ 是帽子矩阵 H 的对角线元素 $h_{ii} = [H]_{ii}$，也叫 杠杆值 （ R 语言里面 htvalues(model) 函数）
	- $\hat{\sigma^2}$ 是线性回归算出来的
	- 模型正确，标准化残差 $r_i$ 应该近似服从 $N(0,1)$
- **学生化残差（Studentisierte Residuen）**：标准化残差中，$\hat{\sigma}$ 的计算用到了**所有残差**（包括 $\hat{\varepsilon}_i$ 本身）。如果第 $i$ 个观测是异常值，它的大残差会**膨胀** $\hat{\sigma}$，从而**掩盖**自己的异常性
	- $r_i^* := \frac{\hat{\varepsilon}_i}{\hat{\sigma}_{(i)}\sqrt{q_{ii}}}, \quad i = 1, \ldots, n$
	- 它服从 $t(n - p' - 1)$ 分布，因此可以直接用 $t$ 分布的临界值来判断异常值
	- **学生化标准差只能处理一个异常值，实际会有多个异常值，要用其他方法处理**
	- **搞这些目的**：建模后不检查残差，会由于一个异常值，把回归系数带偏，结论完全错误
- **交叉验证残差（Kreuzvalidierungs-Residuen）**：用 **删除第 $i$ 个观测后** 的估计 $\hat{\boldsymbol{\beta}}_{(i)}$ 来预测第 $i$ 个观测
	- $e_{(i)} := y_i - \mathbf{x}_i'\hat{\boldsymbol{\beta}}_{(i)}$
	- **PRESS 统计量**：$\text{PRESS} := \sum_{i=1}^n e_{(i)}^2$
	- **核心公式**：$e_{(i)} = \frac{\hat{\varepsilon}_i}{q_{ii}} = \frac{\hat{\varepsilon}_i}{1 - h_{ii}}$   -- **不需要真的跑 $n$ 次回归**！只需拟合一次完整模型，就能算出所有交叉验证残差
	- 删除 第 $i$ 个点，用剩下的 $n - 1$ 个点建模，预测第 $i$ 个点
```r
model1 <- lm(y ~ x)
model2 <- lm(y ~ I(x^2))

e1 <- residuals(model1)
q1 <- 1 - hatvalues(model1)

e2 <- residuals(model2)
q2 <- 1 - hatvalues(model2)

PRESS1 <- sum((e1/q1)^2)
PRESS2 <- sum((e2/q2)^2)

# 哪个小选择哪个
```

- **递归残差（Rekursive Residuen）**
	- 用于 **时间序列** 数据，用过去预测未来，检验模型是否稳定（例如天气预报）


| 残差类型                       | 公式                                                        | 方差                   | 用途         |
| -------------------------- | --------------------------------------------------------- | -------------------- | ---------- |
| 普通残差 $\hat{\varepsilon}_i$ | $y_i - \mathbf{x}_i'\hat{\boldsymbol{\beta}}$             | $q_{ii}\sigma^2$（不等） | 基本诊断图      |
| 标准化残差 $r_i$                | $\hat{\varepsilon}_i / (\hat{\sigma}\sqrt{q_{ii}})$       | ≈1                   | 可比较的残差图    |
| 学生化残差 $r_i^*$              | $\hat{\varepsilon}_i / (\hat{\sigma}_{(i)}\sqrt{q_{ii}})$ | 服从 $t(n-p'-1)$       | 异常值检测      |
| 交叉验证残差 $e_{(i)}$           | $\hat{\varepsilon}_i / q_{ii}$                            | $\sigma^2/q_{ii}$    | 模型预测能力评估   |
| 递归残差 $\omega_i$            | 见公式 (6.10)                                                | $\sigma^2$（如果正确）     | 时间序列结构变化检测 |

- **数据诊断方法**：
	- **误差项非正态（Die Störterme sind nicht normalverteilt）**
		- **诊断方法**：残差的偏度和峰度、**Normal Q-Q Plot**
		- QQ图（Quantile-Quantile Plot，分位数-分位数图）是统计学中用来判断数据是否服从某个理论分布（最常见的是正态分布）的可视化工具
			- 把你的数据从小到大排序后得到"**样本分位数**"，作为 Y 轴
			- 再把对应的理论分布（比如标准正态分布）的分位数作为 X 轴
			- 然后把这些点画出来，如果数据确实服从那个理论分布，**所有的点就会大致落在一条 45 度的直线上**

	- **异方差（Heterogene Varianzen）**
		- $\text{Var}(\varepsilon_i)$ 依赖于 $i$（即不同观测的误差方差不同） -- **残差的方差和残差自身相关**
		- **诊断方法**：残差图（$\hat{\varepsilon}_i$ 对 $\hat{Y}_i$）。典型的异方差模式是"喇叭形"——随着 $\hat{Y}_i$ 增大，残差的散布也增大
		- **治疗方法**：对 $Y$ 做变换（如 $\ln(Y)$ 或 $\sqrt{Y}$），加权最小二乘（WLS）

- **Durbin-Watson 检验** -- **检验数据不独立！！！**
	- 通常是因为**数据有时间顺序**，而模型里**遗漏了某些慢变化的因素**，这些没建模的因素让相邻时间点的误差"**抱团**"
	- DW 检验 是看"**第 $t$ 个残差和第 $t-1$ 个残差是不是有关联**"
	- 你拿到一组时间序列数据，跑 lm()，然后跑 dmtest()，看 DW值落在哪个区域

- **异常值与高杠杆点（Ausreißer und High Leverage Points）**

	- **Leverage（杠杆值）：**

| 概念                            | 定义                     | 空间             |
| ----------------------------- | ---------------------- | -------------- |
| **高杠杆点（High leverage point）** | $\mathbf{x}_i$ 远离数据中心  | **$X$ 空间**中的异常 |
| **异常值（Ausreißer）**            | $\varepsilon_i$ 的绝对值很大 | **$Y$ 方向**的异常  |

- 最危险的是：**同时是异常值又是高杠杆点**的观测——它既有能力拉动回归线（高杠杆），又偏离了正确的模式（大残差）
- Leverage（杠杆值）：$h_{ii} := \mathbf{x}_i'(\mathbf{X}'\mathbf{X})^{-1}\mathbf{x}_i$，这是帽子矩阵 $\mathbf{P}$ 的第 $i$ 个对角元素
- $\frac{1}{n} \leq h_{ii} \leq 1$
- **直觉理解**：$h_{ii}$ 衡量的是第 $i$ 个观测点在 $X$ 空间中距离数据中心的 Mahalanobis 距离。$h_{ii}$ 越大，这个点对回归线的"拉力"越大
- $p' =  p + 1$
- **数据首尾的点如果异常，因为拟合算法是要求残差平方和最小，因此会把回归线往异常点拉（这样才能残差小），这就导致回归线失真**

| $h_{ii}$ 的值 | 判断 |
|-------------|------|
| $h_{ii} = p'/n$ | 平均水平 |
| $h_{ii} > 2p'/n$ | **高杠杆点** ⚠️ |

- **Cook 距离**

	- 这衡量的是：**删除第 i 个观测后，所有拟合值整体变化了多少**
	- Cook 距离 = **残差分量** × **杠杆分量** -- 也就是说，**一个观测对回归结果影响大，当且仅当它同时有大残差和高杠杆**

- **模型设定错误（Regressionsgleichung ist nicht korrekt）** 

	- **原因**：遗漏了重要变量、包含了不必要的变量、非线性关系未捕捉、忽略了交互作用
	- **后果**：参数估计和预测有**系统性偏差**。但模型仍可能提供有用的近似

	- **Partial Leverage Plot（偏杠杆图）**
		- 这是一种非常有用的图形工具，用于**在控制其他变量后**，可视化 $y$ 与某个特定变量 $x_k$ 之间的关系
		- **在去除所有其他变量的影响后**，$y$ 和 $x_k$ 之间剩余的关系。如果这个关系是非线性的，说明需要对 $x_k$ 做变换

- **Partial Leverage Plot（偏杠杆图）**
	- **定义**：$\mathbf{X}$ 的列（近似）线性相关
	- **原因**：自变量之间高度相关、实验设计不当、离散变量的编码方式


- **诊断工具**

	- **条件数（Konditionszahl）**：$K(\mathbf{X}) := \sqrt{\frac{\lambda_{\max}}{\lambda_{\min}}}$
		- $\lambda_{\max}, \lambda_{\min}$ 是 $\mathbf{X}'\mathbf{X}$ 的最大和最小特征值


| $K(\mathbf{X})$ 的值 | 判断 |
|---------------------|------|
| $< 10$ | 共线性不严重 |
| $10 \sim 30$ | 中等程度的共线性 |
| $> 30$ | 严重的共线性 ⚠️ |


- **方差膨胀因子（VIF）**
	- **由于共线性，$\beta_j$ 的方差被膨胀了多少倍**
	- $\text{VIF}_j := \frac{1}{1 - R_j^2}$

| $\text{VIF}_j$ 的值 | 含义 |
|--------------------|------|
| 1 | 与其他变量完全不相关 |
| 5 | 方差是无共线性时的 5 倍 |
| 10 | 一般认为是临界值 ⚠️ |
| $\infty$ | 完全共线性（$R_j^2 = 1$） |

- **测量误差（Messfehler）**
	- **原因**：测量仪器误差、调查问卷中的不正确回答等 
	- **向零偏误的直觉**：如果 $x$ 有测量误差，观测到的 $x$ 的变异中有一部分是纯噪声。回归将效应"稀释"到了更大的 $x$ 变异范围上，所以斜率估计偏小。
	- **诊断**：重复测量
