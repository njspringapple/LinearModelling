
- **异方差线性回归模型**：不同观测值的误差具有不同的方差
	- $Y = X\beta + \varepsilon$，$\varepsilon \sim N(0, \sigma^2V)$，$V = diag(v_1,...,v_n)$ 对角阵意味着第 $i$ 个观察的数据的**误差的方差** = $\sigma^2 \cdot v_i$
	- **因此，V 用于描述方差结构的已知矩阵**

| 项目           | WLS（加权最小二乘）                                                          | GLS（广义最小二乘）                                               |
| ------------ | -------------------------------------------------------------------- | --------------------------------------------------------- |
| **核心思想**     | **方差小的观测给大权重，方差大的观测给小权重**                                            | **在 WLS 基础上，进一步允许误差之间存在相关性**                              |
| **误差协方差**    | $\text{Var}(\epsilon)=\sigma^2 V$                                    | $\text{Var}(\epsilon)=\sigma^2 V$                         |
| **$V$ 的形式**  | $V=\text{diag}(v_1,\dots,v_n)$，**对角矩阵**，其中 $v_i=\sigma_i^2/\sigma^2$ | $V$ 为**一般正定矩阵**                                           |
| **$V$ 的含义**  | 误差方差结构（对角）                                                           | 误差方差 + 协方差结构                                              |
| **是否允许异方差**  | ✅ 允许                                                                 | ✅ 允许                                                      |
| **是否允许自相关**  | ❌ 不允许（非对角为 0）                                                        | ✅ 允许（非对角可非零）                                              |
| **权重矩阵 $W$** | $W=V^{-1}=\text{diag}(1/v_1,\dots,1/v_n)$                            | $W=V^{-1}$                                                |
| **变换矩阵**     | $V^{-1/2}=\text{diag}(1/\sqrt{v_1},\dots,1/\sqrt{v_n})$              | $V^{-1/2}$                                                |
| **变换对象**     | $X$ 和 $Y$ 都左乘 $V^{-1/2}$                                             | $X$ 和 $Y$ 都左乘 $V^{-1/2}$                                  |
| **变换后模型**    | $Y^*=X^*\beta+\epsilon^*$                                            | $Y^*=X^*\beta+\epsilon^*$                                 |
| **变换后误差方差**  | $\text{Var}(\epsilon^*)=\sigma^2 I$                                  | $\text{Var}(\epsilon^*)=\sigma^2 I$                       |
| **优化目标**     | $\min_\beta (Y-X\beta)^T W(Y-X\beta)$                                | $\min_\beta (Y-X\beta)^T W(Y-X\beta)$                     |
| **估计量**      | $\hat{\beta}_{WLS}=(X^TWX)^{-1}X^TWY$                                | $\hat{\beta}_{GLS}=(X^TV^{-1}X)^{-1}X^TV^{-1}Y$           |
| **无偏性**      | $E(\hat{\beta}_{WLS})=\beta$                                         | $E(\hat{\beta}_{GLS})=\beta$                              |
| **估计量方差**    | $\text{Var}(\hat{\beta}_{WLS})=\sigma^2(X^TWX)^{-1}$                 | $\text{Var}(\hat{\beta}_{GLS})=\sigma^2(X^TV^{-1}X)^{-1}$ |
| **适用场景**     | 异方差、无自相关                                                             | 异方差 + 自相关（时间序列、空间数据等）                                     |
| **与对方关系**    | WLS 是 GLS 在 $V$ 为对角矩阵时的特例                                            | GLS 是 WLS 的推广                                             |

- 仔细看左右都一样，差异在 V，一个是对角矩阵，一个是普通正定矩阵
- **问题**：实际不知道 $\varepsilon \sim N(0, \sigma^2V)$，所以以上是理论上的（**随机误差是不知道的**）


- **线性混合模型**
	- 目的：为了在分析**分组或重复测量数据时**，既**估计群体的固定效应**，又**合理刻画个体/群组间的随机差异**，从而得到更准确有效的推断
	- 想象每个组有自己的"**基线水平**"，但这个基线水平不是完全自由的参数
	- **带简单随机效应的模型**（Random-Intercept-Modell）： --- **方差分量模型（Varianzkomponenten-Modell）**
		- $Y_{ij} = x'_{ij}\beta + \gamma_i + \epsilon_{ij}, \quad i = 1, \ldots, g; \quad j = 1, \ldots, n_i$
			- $i$：组别（如班级、医院、个体）
			- $j$：组内观测（如学生、患者、时间点）
			- $g$：组的总数
			- $n_i$：第 i 组的观测数
			- $x'_{ij}\beta$：**固定效应部分**（与经典线性模型相同）
			- $\gamma_i$：第 i 组的**随机截距**（Random Intercept）
			- $\epsilon_{ij}$：个体层面的**残差**
		- **分布假设**：
			- $\epsilon_{ij} \sim N(0, \sigma^2) \quad \text{i.i.d.}$
			- $\gamma_i \sim N(0, \sigma^2_\gamma) \quad \text{i.i.d.}$
		- **独立性假设**
			- 残差之间 i.i.d.
			- 随机效应之间 i.i.d.
			- 残差与随机效应之间独立
		- **为什么从称为混合**：$x_{ij}$  - 固定效应，例如是辅导对成绩的提升，$\gamma_i$ - 随机效应，例如是每个班级基础水平的估计
	- **边际模型（Das marginale Modell）**：
		- 只关心**总体平均**的规律，不单独管每个个体/群组自己的随机波动，但承认这些波动会让误差“抱团”（相关）
		- $Y = X\beta + \delta$
			- **固定部分**：Xβ —— 总体平均趋势
			- **误差部分**：把所有个体/群组的随机差异都塞进误差里
		- $\delta \sim N\Big(0, \; \sigma^2 I + \text{diag}[\sigma^2_\gamma e_i e'_i]\Big)$
			- 表示同一群组内的观测有相关性
			- $n_i$ - 第 $i$ 组采集数据数量
			- $\sigma_{\gamma}$ - **随机截距的方差**
			- $\gamma_i \sim N(0,\sigma_{\gamma}^2)$ - **第 $i$ 个群组自己的随机效应**
			- $e_i$ - 长度为 $n_i$ 的全1向量，$e_ie_i^T$ - $n_i$ 阶全1矩阵，$\text{diag}[\sigma^2_\gamma e_i e'_i]$ - 是**分块对角拼接**
			- 随机误差 = **独立随机误差**($\sigma^2I$) + >  由组随机效应贡献的分块对角矩阵，每个对角块是全 1 矩阵乘以 $\sigma_{\gamma}^2$，$$\operatorname{Var}(\delta) =
\begin{pmatrix}
\sigma^2 I_{n_1} + \sigma^2_\gamma e_1 e_1' & 0 & \cdots \\
0 & \sigma^2 I_{n_2} + \sigma^2_\gamma e_2 e_2' & \cdots \\
\vdots & \vdots & \ddots
\end{pmatrix}$$

	- **结果的解释（Interpretation der Ergebnisse）**!!!!!!!!!!!!!!!!!!!!! **Blatt6-2**
		- Intra-Class Correlation (ICC)
			- $\text{ICC} = \frac{\sigma^2_\gamma}{\sigma^2_\gamma + \sigma^2_\epsilon}$   --  ICC 是**同组内两个观测之间的相关系数**
		- **直觉解读：**
			- ICC = 组间方差占总方差的比例
				-  ICC ≈ 0：几乎没有组效应，经典线性模型就够了
				-  ICC ≈ 1：几乎所有变异都来自组间差异
				-  ICC = 0.2：20% 的变异由组效应解释，是很常见的经验值

			- **考试高频考点！** 经常要求解释 ICC 的含义并计算。
