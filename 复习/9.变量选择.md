
- **建模目的**：
	- 可以**描述**模型中的变量如何影响结果
	- 可以**预测**未来值/**估计**目标变量均值
	- 可以**估计**参数
	- 外推到已有数据范围之外（泛化）
	- 了解了变量行为后，可以通过改变输入变量的值来控制过程

- **偏差-方差 权衡**
	- 加入更多变量通常能 **改善训练集拟合**，但可能 **降低新数据预测能力**吗，变量选择本身也会引入不确定 ！！！！！
	- Error = $Bias^2 + Variance + Noice$
	- 模型太简单：高偏差，欠拟合
	- 模型太复杂：高方差，过拟合
	- 好模型：**在偏差和方差之间折中**

![[Pasted image 20260926020204.png|550]]
- 左侧：随着模型变复杂，训练数据集上**误差下降**，测试集上**误差也下降**
- 右侧：随着模型变复杂，训练数据集上误差下降，测试集上**误差反向上升**
- **因此，不是训练数据集上无限制增加模型复杂度，选择合适的模型复杂度，否则导致模型过拟合，对于”未知“数据的推断误差增加**


- **模型优度指标 / Masse fuer die Modellguete**
	- 普通 $R^2$：$R^2=1-\frac{SSE}{SST}$ ----- **问题：加入变量后 $R^2$ 不会下降**，---- **$R^2$ 是模型所有参数共同解释了 Y（因变量），但是不意味着每个变量都显著！！**
	- 调整 $R^2$：$R^2_{adj}=1-\frac{SSE/(n-p-1)}{SST/(n-1)}$ ----- **标准化后，可以用于不同模型的拟合效果对比** -- **如果调整后的 $R_{adj}^2$ 明显小于 $R^2$ ，说明模型参数至少有一个参数不显著**
		- **计算方法**：
			- $R^2_{adj}=1-\frac{(n-1)}{(n - p')}(1 - R^2)$
	- **AIC**：$-2\ell(\widehat{\theta})+2k$
		- $\ell(\widehat{\theta})$ - **最大对数似然**
			- 似然函数：$L(\theta) = \prod_{i=1}^n p(x_i|\theta)$       -- $\theta$ 是模型参数，例如 $\beta_0,...,\beta_{p}$ **含义： 在参数为 $\theta$ 情况下，观察到现在这组数据的概率是多少**
			- 取对数，$\ell(\theta) = ln L(\theta) = \Sigma_{i=1}^n ln p((x_i|\theta))$
			- 求最大值：求导，$\partial \ell(\theta) / \partial \theta = 0$
			- 求解出来的 $\hat{\theta}$  就是 最大似然估计值，然后代回对数似然 $\ell(\theta)$ 得到 AIC 里面第一项
		- $k$ - **模型参数个数**(含截距，含误差项，即 k = p(建模参数个数) + 1（截距） + 1（误差）)
		- **数值越小越好**
		- **计算方法**：
			- $AIC = -2 · loglik(model) + 2(p′ + 1)$， 其中 p‘ = （p+1） 是建模参数数量加1
			- $AIC = nln(SSE) + 2(p' + 1) - nlog(n)$
	- **BIC**：$BIC=-2\ell(\widehat{\theta})+\log(n)k$  --- **BIC 对复杂度惩罚通常比 AIC 更强，倾向于选择参数更小的模型**
		- **贝叶斯信息准则**（Bayesian Information Criterion）
		- $-2\ell(\widehat{\theta})+k \cdot ln(n)$
			- n - 样本数量
		- **数值越小越好**
		- **计算方法**：
			- $BIC = -2 · loglik(model) + ln(n)(p′ + 1)$， 其中 p‘ = （p+1） 是建模参数数量加1
			- $BIC = nln(SSE) + ln(n)(p' + 1) - nln(n)$


- **模型选择基本原则**
	- 有交互项，但是不能没有主效应：
		- $y \sim x_1 + x_1:x_2$  - 有主效应
		- $y \sim x_1:x_2$ - 缺乏主效应，错误！！
	- 自变量之间高度相关，导致多重共线性（Multikonllinearitat)
		- 在做模型选择的时候，先看候选变量的相关性
	- 分类变量要么不加入模型，要么全部加入
	- 交叉验证：用预测能力来评估模型好坏
		- 把数据切分为 K 份
		- 进行 K 轮训练，每轮训练选用 K - 1 份数据做训练数据集，一份数据进行预测，得到 误差 SSE
		- 把 K 轮 SSE相加，得到 CV = SSE_1 + ... + SSE_k
		- **CV 越小的模型，预测能力越好**

- **变量选择方法**：采集导一堆维度数据，怎么知道用哪些？
	- **穷举法（Auswahl nach einem Kriterium）**：K个变量，$2^K$ 个可能模型，分别训练，挑选 AIC/BIC 小的（变量多了算力要求太高）
		- 计算量大，但是可以找到最优
	- **前向选择（forward）**：空模型开始一个个加参数，每加一个参数，选择 $R^2$ 最高的 --- **加进去之后，永远不会被删除，速度快，同理 backward 也是，减少之后不允许加回来**
	- **后向淘汰（backward）**：从有所有参数的模型开始，逐步去掉参数，先去掉1个，去掉 $R^2$ 最高的，直到 AIC 不再下降
		- 前向和后向计算量小，但是不能确保找到全局最优参数集合，而且不同起点和方向，结果可能不稳定
	- **逐步回归 (both)**：向前或者向后只能添加或者删除，不能返回，both是可以添加后反悔删除掉
