（c）推导在线性变量变换下最小二乘估计量的换算公式，变换形式如下：

$$
x_i \rightarrow t_i = a_0 + a_1 x_i,\quad \text{其中 } a_1 \neq 0
$$

$$
y_i \rightarrow u_i = b_0 + b_1 y_i,\quad \text{其中 } b_1 \neq 0
$$

- 原始数据 ($x_i, y_i$) 变换为 ($t_i,u_i$)
- 原始数据 OLS 斜率估计为：$\widehat{\beta}_1=\frac{\sum_{i=1}^n (x_i-\bar{x})(Y_i-\bar{Y})}{\sum_{i=1}^n (x_i-\bar{x})^2}$
- 变换后的斜率估计为 $\widehat{\beta}_1=\frac{\sum_{i=1}^n (t_i-\bar{t})(u_i-\bar{u})}{\sum_{i=1}^n (t_i-\bar{t})^2}$
	- 均值计算：
		- $\bar{t} = a_0 + a_1\bar{x}$
		- $\bar{u} = b_0 + b_1\bar{y}$
	- 分子部分：$\sum_{i=1}^n (t_i-\bar{t})(u_i-\bar{u})$ = $\sum_i^n (a_0 + a_1x_i - a_0 - a_1\bar{x})(b_0 + b_1y_i - b_0 - b_1\bar{y})$ = $\sum_i^n a_1 \cdot (x_i - \bar{x}) \cdot b_1 \cdot (y_i - \bar{y})$
	- 分母部分：$\sum_{i=1}^n (t_i-\bar{t})^2$ = $\sum_{i=1}^n (a_0 + a_1x_i-a_0 - a_1\bar{x})^2$ =  $\sum_{i=1}^n a_1^2 \cdot (x_i- \bar{x})^2$
	- 所以，$\hat{\beta_1} = b_1 \cdot \sum_i^n(x_i - \bar{x}) \cdot b_1 \cdot (y_i - \bar{y}) / a_1 \cdot \sum_{i=1}^n \cdot (x_i- \bar{x})^2$ = $b_1 \cdot \hat{\beta_1}/a_1$
- 原始数据 OLS 截距估计为：$\beta_0 = \bar{y} - \beta_1\bar{x}$  
- 变换后的截距估计为：$\hat{\beta_0} = \bar{u} - \beta_1\bar{t}$  
- 代入，$\hat{\beta_0} = \bar{u} - \hat{\beta_1}\bar{t}$  = $b_0 + b_1\bar{y} - \hat{\beta_1} \cdot (a_0 + a_1\bar{x})$ = $b_0 + b_1\bar{y} - a_0b_1/a_1 \cdot \hat{\beta}_1 - b_1\hat{\beta}_1 \bar{x}$ , 代入 $\bar{y} =\beta_0  - \beta_1\bar{x}$  ，得到：$\hat{\beta_0} = b_0 + b_1\hat{\beta}_0 - a_0b_1/a_1 \cdot \hat{\beta}_1$
- **汇总**：(**数据线性变换后的参数变化**)
	- $\hat{\beta_1}$ = $b_1 \cdot \hat{\beta_1}/a_1$
	- $\hat{\beta_0} = b_0 + b_1\hat{\beta}_0 - a_0b_1/a_1 \cdot \hat{\beta}_1$

#### Blat1-2

**Aufgabe 2：系数估计量的性质**

（a）考虑简单线性回归模型

$$
Y_i = \beta_0 + \beta_1 x_i + \epsilon_i;\quad i = 1,\ldots,n
$$

其假设为

$$
E(\epsilon_i) = 0;\quad i = 1,\ldots,n
$$

$$
Var(\epsilon_i) = \sigma^2;\quad i = 1,\ldots,n
$$

$$
\{\epsilon_i \mid i = 1,\ldots,n\} \text{ 随机独立}
$$

$$
\epsilon_i \sim N(0,\sigma^2);\quad i = 1,\ldots,n
$$

推导系数估计量 $\hat{\beta}_0$ 和 $\hat{\beta}_1$ 的方差 $Var(\hat{\beta}_0)$ 和 $Var(\hat{\beta}_1)$

- $\widehat{\beta}_1=\frac{\sum_{i=1}^n (x_i-\bar{x})(Y_i-\bar{Y})}{\sum_{i=1}^n (x_i-\bar{x})^2}$
	- $= C \cdot (\Sigma(x_i - \bar{x})Y_i - \sum (x_i - \bar{x})\bar{Y})$,  $C = 1/\sum_{i=1}^n (x_i-\bar{x})^2 = 1/S_{xx}$
	- 因为 $\bar{Y}$ 是个常数，所以 $\sum (x_i - \bar{x})\bar{Y} = 0$  -- x 所有数和均值之差的若干倍数（$\bar{Y}$）求和，正负抵消
	- $= C \cdot \Sigma(x_i - \bar{x})Y_i$
- $Var(\bar{\beta}_1) = Var(C \cdot \Sigma(x_i - \bar{x})Y_i)$ = $Var(\Sigma C \cdot (x_i - \bar{x}) \cdot Y_i)$
- 令 $C \cdot (x_i - \bar{x}) = \omega$
- $Var(\bar{\beta}_1) = Var(\sum \omega_i \cdot Y_i)$ = $\sum \omega_i^2 \cdot Var(Y_i)$ 
- $Var(Y_i) = Var(\beta_0 + \beta_1x_i + \epsilon_i)$ = $Var(\epsilon_i)$   -- $\beta_0, \beta_1, x_i$ 都没有随机性，所有当常数处理，没有方差
- $Var(\hat{\beta}_1)$ = $\sum \omega_i^2 \cdot Var(\epsilon_i)$ = $\sum \omega_i^2 \cdot \sigma^2$ = $\sigma^2 \cdot \sum \omega_i^2$
- $\Sigma \omega_i^2 = \sum ((x_i - \bar{x})/S_{xx})^2$ = $1 / S_{xx}$
- **所以**，$Var(\bar{\beta}_1) = \sigma^2/S_{xx}$

- $\hat{\beta_0} = \bar{Y} - \hat{\beta_1}\bar{x}$  
- $Var(\hat{\beta}_0)$ = $Var(\bar{Y} - \hat{\beta}_1 \bar{x})$ = $Var(\bar{Y}) + \bar{x}^2Var(\hat{\beta_1}) - 2\bar{x}Cov(\bar{Y},\hat{\beta}_1)$  
- $Var(\bar{Y})$ = $Var(\sum Y_i/n)$ = $1/n^2 \cdot Var(\sum Y_i)$ = $1/n^2 \cdot \sum  Var(Y_i)$ = $1/n^2 \cdot \sum  Var(\beta_0 + \beta_1x_i + \epsilon_i)$ = $1/n^2 \cdot \sum Var(\epsilon_i)$
	- $=n\sigma^2/n^2 = \sigma^2/n$
- $Cov(\bar{Y},\hat{\beta}_1)$ = ... = 0 (**过程有点复杂**)
- **所以**，$Var(\hat{\beta}_0)$  = $\sigma^2/n$ + $\bar{x}^2 \sigma^2/S_{xx}$ = $\sigma^2(1/n + \bar{x}^2/S_{xx})$


**要点**：

- **离差平方和**：$S_{xx} = \sum_{i=1}^n (x_i - \bar{x})^2$            -**- 注意，$S_{xx}$ 特指的是 自变量 x 的差异**， 
- **样本方差/无偏样本方差**：$s^2 = S_{xx}/(n-1)$
- **总体方差的有偏估计**：$s^2 = S_{xx}/n$
- $\beta_0,\beta_1$ 是未知常数，不是随机变量，方差为0
- $\epsilon$ 是随机误差，属于随机变量，所以有方差


（b）借助 R 中的模拟说明，（b）部分所描述的简单线性回归模型的系数估计量具有以下分布：

$$
\hat{\beta}_0 \sim N(\beta_0, Var(\hat{\beta}_0))
$$

$$
\hat{\beta}_1 \sim N(\beta_1, Var(\hat{\beta}_1))
$$

为此使用以下回归关系进行 $N = 10{,}000$ 次模拟：

$$
Y_i = -2 + 3.5 \cdot x_i + \epsilon_i
$$

其中

$$
\epsilon_i \sim N(0, 10)
$$



- **模拟思路**
	- 进行 N = 10000 次模拟，每次：
		- 固定一个 x_i, 例如， 1，2，3，... n
		- 生成误差 $\epsilon_i \sim N(0,1)$
		- 计算 $Y_i = -2 + 3.5 \cdot x_i + \epsilon_i$
		- 对于 Yi 关于 xi 做简单线性回归
		- 记录下来截距和斜率的估计值

```r
set.seed(123)

N <- 10000
# 样本量
n <- 100
# 真实参数
beta0 <- -2
beta1 <- 3.5
# 随机误差的方差
sigma2 <- 10
sigma <- sqrt(sigma2)

# 一批x
x <- 1:n

# 根据上面计算出来的理论方差
Sxx <- sum((x - mean(x))^2)
var_beta1_theory <- sigma2 / Sxx
var_beta0_theory <- sigma2 * (1/n + mean(x)^2 / Sxx)

# 保存每次模拟中估计出来的系数
beta0_hat <- numeric(N)
beta1_hat <- numeric(N)

for( i in 1:N) {
	# 生成 n 个数据的随机误差
	epsilon <- rnorm(n, mean = 0, sd = sigma)
	# 向量运算
	y <- beta0 + beta1 * x + epsilon
	# 回归
	fit <- lm(y ~ x)
	# 保存估计出来的参数
	beta0_hat[i] <- coef(fit)[1]
	beta1_hat[i] <- coef(fit)[2]
}

cat("beta0 理论均值：", beta0 , "\n")
cat("beta0 模拟均值：", mean(beta0_hat) , "\n")

cat("beta1 理论均值：", beta1 , "\n")
cat("beta1 模拟均值：", mean(beta1_hat) , "\n")

cat("beta0 理论方差：", var_beta0_theory , "\n")
cat("beta0 模拟均值：", var(beta0_hat) , "\n")

cat("beta1 理论方差：", var_beta1_theory , "\n")
cat("beta1 模拟均值：", var(beta1_hat) , "\n")

# 绘图：beta0, 看模拟出来数据的直方图的分布和理论分布差异
hist(beta0_hat, breaks = 50, freq = FALSE,
     main = expression("模拟分布： " * hat(beta)[0]),
     xlab = expression(hat(beta)[0]),
     col = "lightblue", border = "white")
curve(dnorm(x, mean = beta0, sd = sqrt(var_beta0_theory)),
      add = TRUE, col = "red", lwd = 2)
      

# 绘图：beta1
hist(beta1_hat, breaks = 50, freq = FALSE,
     main = expression("模拟分布： " * hat(beta)[1]),
     xlab = expression(hat(beta)[1]),
     col = "lightgreen", border = "white")
curve(dnorm(x, mean = beta1, sd = sqrt(var_beta1_theory)),
      add = TRUE, col = "red", lwd = 2)

```


模拟得到的均值、方差和直方图均与理论结果一致，**从而验证了系数估计量的正态分布性质**

**要点**：

1. 系数估计的方差随着误差方差增大而增大 
	- $Var(\bar{\beta}_1) = \sigma^2/S_{xx}$ 
	- $Var(\hat{\beta}_0)$  = $\sigma^2(1/n + \bar{x}^2/S_{xx})$
	- **也就是说数据采集的噪声越大，估计越不准**
2. 样本量越大，估计越精准
3. x 的变异程度越大 （ $S_{xx}$ 在分母上），斜率估计越精准
4. 两个估计量通常相关，但是 $\bar{Y}$ 和 $\hat{\beta}_1$ **斜率通常不相关**
5. 最小二乘估计量 $\hat{\beta}_0,\hat{\beta}_1$ 是无偏正态估计量，其精度取决于误差方差 $\sigma^2$、样本量 $n$、自变量 $x$ 的变异程度 $S_{xx}$ 以及 $x$ 的均值 $\bar{x}$。误差越小、样本越大、$x$ 变异越大，估计越精确；截距估计还特别受 $x$ 均值是否接近 0 的影响。

**(e)** 使用 R 包 `visreg`，为每个影响因素可视化其对线性预测量的个体贡献以及相应的估计不确定性。

用 R 包 `visreg` 画图，看看**每个自变量单独对 CO₂ 排放预测有多大影响，以及这个影响有多不确定**!!

有 4 个自变量。你想知道：**每个变量各自贡献了多少？**

**两种看法**：

1. 把其它变量固定在 “平均值”， 只让一个变量变化，看预测值如何变化
2. 不固定其它变量，而是看这个变量变化一个单位，预测值变化多少

**不确定性**：画出来的曲线周围会有一条**阴影带**，表示：**这个预测有多准？** 带子越宽 → 越不确定；越窄 → 越有把握。

**注意，visreg 参数 type = conditional**

