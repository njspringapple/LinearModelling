#### 12 ex1-1

证明：每个向量 $x\in\mathbb R^n$，其中 $n\in\mathbb N$，都可以表示为标准单位向量 $e_1,\dots,e_n\in\mathbb R^n$ 的线性组合，即存在系数 $\lambda_1,\dots,\lambda_n\in\mathbb R$，使得 $x=\sum_{i=1}^n \lambda_i e_i$，标准单位向量 $e_i$，$i\in\{1,\dots,n\}$，定义为

$$
e_1=
\begin{pmatrix}
1\\
0\\
0\\
\vdots\\
0
\end{pmatrix},
\quad
e_2=
\begin{pmatrix}
0\\
1\\
0\\
\vdots\\
0
\end{pmatrix},
\quad
\dots,
\quad
e_n=
\begin{pmatrix}
0\\
0\\
0\\
\vdots\\
1
\end{pmatrix}.
$$

因此需要证明：对每个 $x\in\mathbb R^n$，都存在 $\lambda_1,\dots,\lambda_n\in\mathbb R$，使得 $x=\sum_{i=1}^n \lambda_i e_i$

-  $\sum_{i=1}^n \lambda_i e_i$ = $\lambda_1 \cdot (1,0,...,0) + \lambda_2 \cdot (0,1,...,0) + ... + \lambda_n \cdot (0,0,...,1)$
- $=(\lambda_1,\lambda_2,...,\lambda_n)$
- 因此总可以选择  $\lambda_1,\dots,\lambda_n\in\mathbb R$ ，使得 $x=\sum_{i=1}^n \lambda_i e_i$



#### 13 线性映射证明1  ex2-1


设 $f,g:\mathbb R^n\to\mathbb R^m$ 是线性映射，且 $a,b\in\mathbb R$。证明：$h=af+bg:\mathbb R^n\to\mathbb R^m$ 由 $h(x)=af(x)+bg(x)$ 定义，也是线性的。

- **加法保持**：

	- 设 u = R^n,  v = R^n
	- h(u+v) = af(u+v) +bg(u+v)  
	- 因为 f，g 是线性映射
	- f(u+v) = f(u) + f(v) ，g(u+v) = g(u) + g(v)
	- 所以，
	- = a(f(u) + f(v)) + b(f(v) + g(v))
	- = af(u) + bg(v) + af(v) + bg(v)
	- = h(u) + h(v)

 **数乘保持性**：

- h(λu)  = af(λu) + bg(λu) = 
- 因为 f，g 是线性映射
- f(λu) = λf(u), g(λu) = λg(u)
- 所以，
- = aλf(u) + bλg(u)
- =λ(af(u) + bf(u))
- =λh(u)

**考点和技巧：**

1. **映射线性性性质：加法封闭，数乘封闭**
2. **证明时候可以两个方向往中间汇聚，一面从要证明的左边开始展开，化简，一面从右边展开，化简，然后看两头如何通过一些基础转换后相等**


#### 14 线性映射证明2

判断下列映射中哪些是线性映射。

(a) $f:\mathbb R^2\to\mathbb R^2$，

$$
\begin{pmatrix}
x\\
y
\end{pmatrix}
\mapsto
\begin{pmatrix}
3x+2y\\
4x+y
\end{pmatrix}.
$$

- **加法保持性** ：对于任意的 u，v，f(u+v) = f(u) + f(v)

	- **u = (x_1, y_1)  v = (x_2,y_2)**
	- **f(u+v)** = f((x_1,y_1) + (x_2,y_2)) = f((x_1+x_2, y_1 + y_2)) = ... **利用映射条件** .. = (3(x_1+x_2) + 2(y_1+y_2), 4(x_1+x_2) + (y_1+y_2))  -- 注意，这里映射后脱掉了 f
	- = (3x_1 + 3x_2 + 2y_1 + 2y_2, 4x_1 + 4x_2 + y_1 + y_2)
	- =((3x_1 + 2y_1),(4x_1 + y_1)) + ((3x_2 + 2y_2),(4x_2 + y_2))
	- =f((x_1,y_1)) + f((x_2,y_2))
	- =**f(u) + f(v)**

- **数乘保持性**：对于任意 λ，f(λu) = λf(u) 

	- f(λ(x,y)) = f((λx,λy)) = (3λx+2λy, 4λx + λy) = λ(3x+2y, 4x+y) = λf((x,y))

(b) $h:\mathbb R\to\mathbb R$，$x\mapsto x^3$

- 检查数乘性：
	- h(λx) = λ^3x^3
	- λh(x) = λx^3
	- 很明显，在 λ != 1 或者 λ != 0 时候，上面两个肯定不相等，但是定义要求是对于任意 λ，所以，给个反例
	- 设 λ = 2，x = 3
	- h(λx) = 2^33^3 = 27 x 8 = 216
	- λh(x) = 2 3^3 = 54
	- 因此，不是线性映射
