## 一、从 Internet 分层模型到网络接入层

第 5 章承接前几章的 Internet 分层模型。

应用层、传输层、网络层已经在前面章节中讨论过。本章重点下移到 **Netzanschluss**，即网络接入层/链路接入部分。

在 Internet 分层模型中：

应用层调用类似 `send_http_request(host, message)` 的接口。传输层收到上层交付的数据后，向网络层传递：

`ICI = { address }`，表示到网络层所需的控制信息，即目标地址；  
`ID = { payload }`，表示要承载的实际数据。

随后，网络层向网络接入层交付：

`ICI = { next_hop }`，表示下一跳；  
`ID = { packet }`，表示要在下一段链路上传输的 IP 分组。

因此，本章关心的问题是：当网络层已经决定了下一跳，底层如何在一个局域网或物理介质上把这个分组真正送到下一台设备？

## 二、Local Area Networks 与 Broadcast-Domäne

本章首先引入 **Local Area Networks**，即局域网。

局域网可以有不同形态：

- **Switched LAN**：通过交换机连接端系统。
- **Wireless LAN**：通过无线介质连接端系统。

这里出现一个重要概念：**Broadcast-Domäne**，即广播域。

在一个广播域中，发送到广播地址的帧可以被同一广播域内的所有相关设备接收。也就是说，在二层网络里，并不是只有目标主机可能“听到”传输，很多节点可能都处在同一个共享或逻辑共享的通信范围内。

这会带来三个核心问题：

1. 如何在二层中标识端点？
2. 如果多个设备共享同一介质，如何避免或处理冲突？
3. 如何在不可靠的物理传输上尽量实现可靠的数据传输？

这些问题就是数据链路层，也就是 **Sicherungsschicht**，要处理的核心任务。

## 三、数据链路层的任务

ISO/OSI 模型中，第 2 层是 **Sicherungsschicht**，也就是数据链路层。

它的任务包括：

- **端点寻址**：同一广播域中的设备都可能接收到传输，因此必须知道帧应该交给谁。
- **介质访问控制**：介质不一定是独占资源，多个节点可能同时尝试发送。
- **冲突避免或冲突处理**：在共享介质中，需要减少或检测 Kollision。
- **可靠传输的基础支持**：通过 Fehlererkennung 或 Fehlerkorrektur 检测/纠正传输错误。

这里的数据链路层不是端到端意义上的可靠性层。TCP 那样的端到端可靠性发生在传输层；而数据链路层更关注相邻节点之间、一个局部网络片段上的传输。

## 四、第二层寻址：MAC-Adressen

在第 2 层中，寻址依靠 **MAC-Adressen**，即 MAC 地址。

MAC 地址也称为 **physische Adresse**，物理地址。它用于标识某个二层网络接口，例如网卡、LAN 适配器或 WiFi 适配器。

几个重点：

- 每个第 2 层网络接口都有自己的 MAC 地址。
- 路由器通常有多个网络接口，因此有多个 MAC 地址。
- 主机也可能有多个 MAC 地址，例如一个 LAN 网卡和一个 WiFi 适配器各有一个。
- MAC 地址通常是 6 字节，也就是 48 bit。
- MAC 地址通常由厂商在出厂时分配。
- MAC 地址没有 IP 地址那样的层次结构。

这一点很关键：**IP 地址常用于网络层路由，MAC 地址用于本地链路上的下一跳传输。**

例如，主机 A 可能知道目标 IP 地址，但如果要在同一个 LAN 中真正发送 Ethernet 帧，还必须知道对应接口的 MAC 地址。

## 五、Broadcast MAC-Adresse

二层广播地址用于向同一 LAN 中所有节点发送帧。

典型的 Ethernet 广播 MAC 地址是：

`FF-FF-FF-FF-FF-FF`

当一个帧使用这个目标 MAC 地址时，同一广播域中的所有节点都会接收并检查该帧。

ARP 请求就使用这种广播机制，因为发送方一开始并不知道目标 IP 地址对应的 MAC 地址。

## 六、ARP：从 IP 地址到 MAC 地址

**ARP** 的全称是 **Address Resolution Protocol**，地址解析协议。

ARP 的作用是：在一个 LAN 中，把 IP 地址映射到 MAC 地址。

问题场景：

主机 A 想给主机 C 发送数据。A 知道 C 的 IP 地址，但 Ethernet 帧需要目标 MAC 地址。那么 A 如何知道 C 的 MAC 地址？

答案是使用 ARP。

### ARP Table

每台主机和路由器通常维护自己的 **ARP Table**，即 ARP 表。

ARP 表记录：

IP 地址 -> MAC 地址

Linux 中可以通过类似命令查看：

`cat /proc/net/arp`

或者：

`arp -a`

### ARP 查询过程

如果发送方本地没有目标 IP 地址对应的 MAC 地址，它会执行 ARP 查询：

1. 主机构造一个 **ARP-Anfrage**，也就是 ARP 请求。
2. 请求中包含源 MAC、源 IP、目标 IP。
3. 目标 MAC 使用广播地址 `FF-FF-FF-FF-FF-FF`，让同一 LAN 中所有节点都能收到。
4. 所有主机和路由器接收这个 ARP 请求。
5. 只有拥有目标 IP 地址的节点进行响应。
6. 响应中包含它自己的 MAC 地址。
7. 发送方把这个映射写入本地 ARP 表。

之后，发送方就可以用目标 MAC 地址封装 Ethernet 帧。

### ARP 与下一跳

需要注意：如果目标 IP 不在同一个子网内，发送方通常不会解析最终目标主机的 MAC 地址，而是解析默认网关/下一跳路由器的 MAC 地址。

也就是说：

- IP 层关心最终目的 IP。
- 链路层每一跳只关心下一跳 MAC。

## 七、回顾：数据链路层任务

到这里，数据链路层的第一个问题“端点寻址”已经解决：使用 MAC 地址，并通过 ARP 在 IP 与 MAC 之间建立本地映射。

后续要处理第二个问题：共享介质中的访问冲突。

## 八、Wireless LAN 与共享介质

无线局域网是典型的共享介质环境。

无线信号在空气中传播，多个设备可能处于同一通信范围。如果多个设备同时发送，就可能互相干扰。

在共享介质中，每个发送方都必须面对两个问题：

- 什么时候可以发送？
- 如果和别人同时发送导致冲突，如何处理？

这引出 **Vielfachzugriff**，即多路访问/多用户访问问题。

## 九、Vielfachzugriff：多路访问问题

**Vielfachzugriff** 指多个节点共享同一个传输介质时，如何协调发送。

课件中区分两种基本连接方式：

- **Punkt-zu-Punkt**：点对点连接，两个端点之间独占一条链路。
- **Broadcast/Shared Medium**：广播或共享介质，多台设备共享同一个传输环境。

在共享介质中，一个节点发送的帧可能被所有节点听到。每个节点都要判断：

- 这个帧是不是发给我的？
- 我现在能不能发送？
- 如果发生冲突，如何重试？

## 十、多路访问协议的要求

理想的多路访问协议应该满足：

- **效率高**：介质空闲时，应尽可能充分利用带宽。
- **分散式**：不依赖单一中央控制节点，否则中央节点会成为瓶颈或单点故障。
- **公平性**：多个节点都有机会发送。
- **稳定性**：在负载高时不会完全崩溃。
- **实现简单**：协议不能过于复杂，否则硬件和软件成本会变高。

这类协议的典型例子包括 Aloha、Slotted Aloha、CSMA/CD、MACA 等。

## 十一、Aloha-Verfahren

**Aloha** 是一种早期、简单的随机接入方法。

基本思想：如果一个节点有帧要发送，就尝试发送。如果发生冲突，则等待一段随机时间后重试。

这种方法非常简单，但效率不高，因为两个节点只要发送时间重叠，就会导致冲突。

课件提到 Aloha 的不同变体：

- Pure Aloha
- Slotted Aloha
- Reservation Aloha

本章重点讨论 Pure Aloha 和 Slotted Aloha。

## 十二、Slotted Aloha

**Slotted Aloha** 把时间划分为固定的时间槽。

前提条件：

- 每个帧大小固定为 `L` bit。
- 传输速率为 `R` bit/s。
- 发送一个帧需要 `L/R` 秒。
- 时间被切成长度为 `L/R` 的槽。
- 节点只能在槽开始时发送。
- 节点之间需要同步时钟。

### Slotted Aloha 的流程

如果某个节点有帧要发送：

1. 等待下一个时间槽开始。
2. 在槽开始时发送帧。
3. 如果没有其他节点在同一槽发送，则成功。
4. 如果有多个节点同槽发送，则发生冲突。
5. 发生冲突后，节点以某种概率或随机等待策略重试。

### Slotted Aloha 的评价

优点：

- 简单。
- 分散式。
- 比 Pure Aloha 更高效，因为冲突只发生在同一时间槽中。

缺点：

- 需要全局时间同步。
- 空闲槽会浪费介质。
- 冲突槽也会浪费介质。
- 在负载较高时效率明显下降。

## 十三、Pure Aloha

**Pure Aloha** 不划分时间槽。

节点一旦有帧要发送，就立即发送。

优点是无需时钟同步，实现更简单。缺点是冲突窗口更大：只要其他帧在当前帧传输前后一定时间范围内重叠，就可能冲突。

因此 Pure Aloha 的最大效率约为 Slotted Aloha 的一半。

## 十四、CSMA/CD：载波侦听与冲突检测

**CSMA/CD** 的全称是 **Carrier Sense Multiple Access with Collision Detection**。

它比 Aloha 更聪明：发送前先“听一听”介质是否空闲。

基本规则：

1. **Carrier Sensing**：发送前检查介质是否空闲。
2. 如果介质空闲，则开始发送。
3. 如果介质忙，则等待。
4. 发送过程中继续检测是否发生冲突。
5. 如果检测到冲突，则立即中止发送。
6. 发送 Jam Signal，让其他节点也知道发生了冲突。
7. 等待一段随机退避时间后重试。

### 为什么侦听后仍会冲突？

即使发送前检查到介质空闲，也可能发生冲突。

原因是信号传播需要时间。假设节点 A 和 B 位于链路两端，A 刚开始发送时，B 可能还没有接收到 A 的信号，因此 B 也认为介质空闲并开始发送。两个信号在介质中相遇后发生冲突。

因此，冲突检测和最小帧长度都与传播时延有关。

## 十五、Binary Exponential Backoff

CSMA/CD 中发生冲突后，节点不会立刻重发，而是等待随机时间。

**Binary Exponential Backoff**，二进制指数退避，思想是：

- 第 `N` 次冲突后，从一个随 `N` 增大的范围中随机选择等待时间。
- 冲突次数越多，等待范围越大。
- 这样可以降低多个节点再次同时发送的概率。

Ethernet 使用这种机制来处理共享介质中的冲突。

## 十六、Collision Avoidance：MACA 与 MACAW

无线网络中很难像有线 Ethernet 那样可靠地检测冲突。

原因包括：

- 无线发送时自身信号太强，难以同时监听其他节点。
- 存在隐藏终端问题。
- 信号覆盖范围不完全一致。

因此无线环境更偏向 **Collision Avoidance**，即冲突避免。

### MACA

**MACA** 的全称是 **Multiple Access with Collision Avoidance**。

它使用两个控制消息：

- **RTS**：Request To Send，请求发送。
- **CTS**：Clear To Send，允许发送。

基本思路：

1. 发送方先发 RTS。
2. 接收方如果可以接收，则回复 CTS。
3. 周围节点听到 RTS 或 CTS 后，暂时保持安静。
4. 发送方再发送真正的数据帧。

这样可以减少隐藏终端导致的数据帧冲突。

### MACAW

**MACAW** 是 MACA for Wireless，是对 MACA 的扩展。

它在无线场景中进一步细化了 RTS/CTS 和确认等流程，让无线介质访问更稳健。

## 十七、Switched LAN

在交换式 LAN 中，设备不再通过单一共享总线通信，而是连接到交换机。

交换机的出现改变了冲突问题：

- 每条主机到交换机的链路可以视为独立链路。
- 交换机内部根据 MAC 地址转发帧。
- 交换机端口可以有缓冲队列。
- 在全双工交换式 Ethernet 中，通常不再需要 CSMA/CD。

因此，现代有线局域网中，“共享介质冲突”已经不再像早期总线 Ethernet 那么核心。

## 十八、Switches：自学习交换机

交换机是二层的 **Koppelkomponente**，即互连设备。

它的主要任务是根据目标 MAC 地址，把 Ethernet 帧转发到正确端口。

交换机通常是 **self-learning**，自学习的：

1. 收到一个帧时，查看源 MAC 地址。
2. 记录该源 MAC 是从哪个端口来的。
3. 将这个 MAC-Port-Paar 写入转发表。
4. 如果之后看到目标 MAC 在表中，就只转发到对应端口。
5. 如果目标 MAC 未知，就向除输入端口外的其他端口泛洪。

交换机表项通常有老化时间，长时间不用的表项会被删除。

## 十九、VLAN：虚拟局域网

**VLAN** 是 **Virtual LAN**，虚拟局域网。

普通 LAN 的问题是：物理拓扑和逻辑拓扑高度绑定。处在同一交换网络中的设备可能都在同一广播域中。

VLAN 的思想是：把物理 LAN 抽象成多个逻辑 LAN。

也就是说，物理上连接到同一组交换机的主机，可以逻辑上属于不同的 VLAN；不同 VLAN 之间默认像不同 LAN 一样隔离。

### VLAN 的作用

VLAN 可以用于：

- 划分广播域。
- 隔离不同部门或用户组。
- 让逻辑网络结构不完全依赖物理布线。
- 在多个交换机之间维护一致的逻辑 LAN。

### VLAN 的形成方式

课件提到几种 VLAN 形成方式：

1. **基于端口**：交换机的某些端口固定属于某个 VLAN。
2. **基于 MAC 地址**：根据主机 MAC 地址决定 VLAN。
3. **基于三层地址**：根据网络层地址决定 VLAN。

基于端口的方式简单，但主机换端口时 VLAN 归属可能改变。基于 MAC 地址更灵活，但新主机需要维护映射关系。

### VLAN Tagging

如果 VLAN 跨越多个交换机，就需要在交换机之间传递 VLAN 信息。

方法是 **VLAN-Tagging**：在 Ethernet 帧中加入 VLAN 标记。

标记中包含：

- VLAN-Protocol-ID
- Priority
- VLAN-ID

这样，交换机在转发帧时可以知道该帧属于哪个 VLAN。

### VLAN 的复杂性

VLAN 提高了网络组织能力，但也增加复杂度。

复杂性可能导致配置错误，例如端口归属错误、Tag 配置不一致、VLAN 间隔离失效等。

因此 VLAN 是很实用但需要谨慎管理的技术。

## 二十、差错检测与差错处理

接下来回到数据链路层的第三个任务：可靠传输的基础支持。

物理传输中可能出现错误：

- 信号衰减。
- 噪声干扰。
- 电磁干扰。
- 传输介质质量问题。
- 多个连续 bit 受影响的 Burst Fehler。

数据链路层不能保证所有错误都被修复，但可以通过校验机制检测错误，必要时丢弃错误帧或请求重传。

## 二十一、Paritätsprüfung：奇偶校验

最简单的差错检测方法是 **Paritätsbit**。

思路：在数据后加一个额外 bit，使整个 bit 串中 1 的个数满足某种规则。

- **Gerade Parität**：偶校验，1 的个数为偶数。
- **Ungerade Parität**：奇校验，1 的个数为奇数。

如果传输后 1 的个数不符合规则，就说明发生了错误。

### 奇偶校验的局限

奇偶校验只能可靠检测奇数个 bit 错误。

如果两个 bit 同时翻转，奇偶性不变，错误就可能漏检。

因此，简单奇偶校验大约只能检测一部分错误；对突发错误尤其有限。

## 二十二、Paritätsmatrix

为了改进简单奇偶校验，可以使用 **Paritätsmatrix**。

思路是把数据排成矩阵，对行和列分别计算奇偶校验。

这样，如果单个 bit 出错，可以通过出错行和出错列定位该 bit。

优点：

- 比单一奇偶位更强。
- 能定位并纠正某些单 bit 错误。

缺点：

- 需要更多校验位。
- 对复杂多 bit 错误仍然有限。

## 二十三、CRC：循环冗余校验

**CRC** 的全称是 **Cyclic Redundancy Check**，德语为 **Zyklische Redundanzprüfung**。

CRC 是网络中非常常见的差错检测方法。

基本思想：

1. 把待发送的数据看作一个二进制多项式。
2. 使用一个预先约定的 **Generator-Polynom**，生成多项式。
3. 发送方计算 CRC 校验值并附加到数据后面。
4. 接收方用同样的生成多项式重新计算。
5. 如果余数不符合预期，则认为数据出错。

常见 CRC 标准包括：

- CRC-16
- CRC-CCITT
- CRC-32

Ethernet 帧尾部使用 4 字节校验值，属于 CRC 方法。

CRC 不能纠正所有错误，但能高概率检测常见传输错误，尤其适合检测突发错误。

## 二十四、Hammingabstand：汉明距离

**Hammingabstand**，汉明距离，是两个码字之间不同 bit 的数量。

例如，两个二进制码字只有一位不同，则汉明距离为 1。

对一个编码系统而言，最小汉明距离越大，错误检测和纠正能力越强。

一般来说：

- 最小汉明距离为 `h` 的编码，可以检测最多 `h - 1` 个 bit 错误。
- 可以纠正的错误数量通常为 `⌊(h - 1) / 2⌋`。

核心直觉：如果有效码字之间离得很远，少量 bit 错误不会把一个合法码字变成另一个合法码字，因此更容易发现或纠正错误。

## 二十五、Sicherungsschicht 小结

到这里，数据链路层的三个主要任务已经覆盖：

1. **端点寻址**：MAC 地址，ARP。
2. **介质访问控制**：Aloha，CSMA/CD，MACA，Switching。
3. **差错检测/纠正**：Parity，CRC，Hammingabstand。

接下来课件进入一个具体而重要的链路层技术：Ethernet。

## 二十六、Ethernet：概览

Ethernet 是最重要的局域网技术之一。

它工作在网络接入层/数据链路层附近，定义了帧格式、MAC 地址使用、错误检测以及早期共享介质中的冲突处理方式。

传统 Ethernet 使用 CSMA/CD。现代交换式全双工 Ethernet 中，CSMA/CD 通常不再实际使用，但它仍然是理解 Ethernet 历史和最小帧长度设计的重要背景。

## 二十七、Ethernet Rahmenaufbau：帧结构

Ethernet 帧由多个字段构成。

课件列出的关键字段包括：

- **Präambel**：前导码，用于同步接收方。
- **Ziel-MAC-Adresse**：目标 MAC 地址。
- **Quell-MAC-Adresse**：源 MAC 地址。
- **Typ/Länge**：表示上层协议类型或长度。
- **Nutzdaten/Payload**：实际承载的数据，例如 IPv4、IPv6 或 ARP。
- **Prüfsumme**：校验和，通常基于 CRC 方法。

### Präambel

Ethernet 前导码常由重复的 `10101010` 模式组成，用于让接收方同步时钟。

它不属于上层数据，而是帮助物理接收过程稳定开始。

### 最小帧长度

Ethernet 有最小帧长度要求。

原因与 CSMA/CD 的冲突检测有关：发送方必须在仍然发送该帧时，有机会检测到远端传播回来的冲突信号。

如果帧太短，发送方可能已经发完并认为成功，而冲突信号还没传播回来。

因此，最小帧长度与最大传播时延、网络直径和 bit time 有关。

### Jam Signal

在 CSMA/CD 中，如果检测到冲突，发送方会发送 **Jam Signal**。

Jam Signal 的作用是确保其他节点也能明显感知到这次冲突，从而停止当前传输并进入退避流程。

## 二十八、从数据链路层到物理层

Ethernet 帧最终还必须变成实际物理信号。

这就进入 **Bitübertragungsschicht**，即物理层。

物理层关心的问题包括：

- bit 如何表示成信号？
- 信号如何在介质上传播？
- 介质会带来哪些限制？
- 如何编码、调制、同步？
- 数据率和误码率受到什么影响？

## 二十九、物理层的任务

物理层负责在真实传输介质上发送和接收 bit。

它涉及：

- 电信号、光信号或无线电磁波。
- 插头、接口、引脚、线缆和适配器。
- 信号状态与 bit 的对应关系。
- 编码与调制。
- 传输速率、带宽、噪声和衰减。

这一层比前面章节更接近硬件，因此本章标题叫 Hardwarenah。

## 三十、Abtasttheorem 与 PCM

课件随后讨论模拟信号如何变成数字数据。

**Abtasttheorem**，采样定理，说明如果要从采样值重建一个带限信号，采样频率必须足够高。

常见例子是电话语音：

- 语音信号按一定频率采样。
- 课件中给出 Abtastrate 为 8 kHz。
- 也就是每 125 微秒采样一次。
- 每个采样值可量化为 256 个等级。
- 256 个等级需要 1 Byte，即 8 bit。

因此电话语音的典型数字化速率可以计算为：

`8000 samples/s * 8 bit = 64000 bit/s`

这就是常见的 64 Kbit/s 语音编码基础。

## 三十一、Abtastung、Quantisierung 与 Codierung

模拟信号数字化通常包括：

1. **Abtastung**：采样，把连续时间信号变成离散时间点的值。
2. **Quantisierung**：量化，把连续幅值映射到有限个等级。
3. **Codierung**：编码，把量化后的值表示为 bit 序列。

采样处理的是时间轴，量化处理的是取值范围，编码处理的是符号表示。

## 三十二、Codierung：编码

编码的核心问题是：如何把信息表示成适合传输、存储或处理的 bit 序列。

课件中区分了不同编码层次：

- **Quellencodierung**：信源编码，目标是减少冗余。
- **Entropiecodierung**：熵编码，例如 Huffman、算术编码、游程编码。
- **Leitungscodierung**：线路编码，把 bit 序列映射为物理信号元素。

### Quellencodierung

信源编码关注的是压缩信息。

例子：

- Lauflängencodierung/Run Length Encoding：把连续重复符号压缩成“次数 + 符号”。
- Huffman-Codierung：给高频符号短码，低频符号长码。
- Transformation：例如 FFT、DCT，用于图像或音频压缩。

JPEG 中就会使用 DCT 和量化等方法。

### Leitungscodierung

线路编码关注的是如何在物理介质上表达 bit。

例如：

- 一个信号状态表示一个 bit。
- 多个信号状态表示多个 bit。
- 需要考虑同步、直流分量、抗干扰能力和实现复杂度。

## 三十三、Baudrate 与 Bitrate

**Bitrate** 是每秒传输多少 bit。

**Baudrate** 是每秒有多少次信号状态变化。

如果一个信号状态只表示 1 bit，则 Bitrate 和 Baudrate 数值相同。  
如果一个信号状态可以表示多个 bit，则 Bitrate 可以高于 Baudrate。

例如 4-Stufencodierung 中，4 个信号状态可以表示 2 bit，因此同样的 Baudrate 下可传输更多 bit。

## 三十四、Manchester-Codierung

课件最后的问题中提到 **Manchester Codierung**。

Manchester 编码是一种线路编码方法，它通过每个 bit 时间中的信号跳变同时表达数据和时钟信息。

优点：

- 有利于接收方同步。
- 不需要长时间保持同一电平。

缺点：

- 相比某些编码方式，需要更高的信号变化频率。
- 带宽利用率不是最高。

## 三十五、Modulation：调制

**Modulation** 是把信息加载到载波信号上的过程。

基本思想：改变载波的某些属性来表示数据。

常见调制维度包括：

- 振幅：Amplitude。
- 频率：Frequenz。
- 相位：Phase。

因此可以有：

- ASK：Amplitude Shift Keying。
- FSK：Frequency Shift Keying。
- PSK：Phase Shift Keying。
- 组合方式，例如 AM-PSK。

调制常用于无线通信、电话线、光通信等场景。

## 三十六、Übertragungsmedien：传输介质

传输介质决定信号如何传播。

课件中提到的介质包括：

- 铜线，例如 Twisted-Pair-Kabel。
- 同轴电缆 Koax。
- 无线电磁波。
- 光纤 Lichtwellenleiter。

介质影响：

- 可用带宽。
- 传播速度。
- 信号衰减。
- 噪声与干扰。
- 误码率。
- 成本和布线难度。

## 三十七、Dämpfung、Rauschen 与 Verzerrung

实际传输中，信号不会完美保持原样。

主要影响包括：

- **Dämpfung**：衰减，信号强度随距离下降。
- **Rauschen**：噪声，随机干扰使信号变形。
- **Verzerrung**：失真，不同频率或幅度分量传播效果不同。
- **Störeinflüsse**：外部干扰，例如电磁干扰。

这些因素都会导致 Bitfehlerrate 上升。

因此，物理层必须在传输速率、距离、介质质量、编码方式和错误率之间做权衡。

## 三十八、Lichtwellenleiter：光纤

**Lichtwellenleiter**，简称 LWL，即光纤。

光纤使用光信号传输数据。

它通常由：

- Kern：纤芯。
- Mantel/Cladding：包层。
- 外部保护层。

组成。

光在光纤中通过反射或折射机制传播。

### Monomode 与 Multimode

光纤可以分为：

- **Monomode**：单模光纤，主要传播一种模式，适合长距离和高带宽。
- **Multimode**：多模光纤，允许多个传播模式，成本较低但长距离性能较弱。

光纤优点：

- 高带宽。
- 低衰减。
- 抗电磁干扰。
- 适合长距离传输。

缺点：

- 连接和安装要求更高。
- 设备成本可能更高。

## 三十九、本章复习问题

课件最后给出若干物理层复习问题，可整理为：

1. **Abtasttheorem 说明什么？**  
   采样频率必须足够高，才能从离散采样值恢复原信号。

2. **什么是 Codierung？**  
   编码是把信息映射为可传输或可存储的符号/bit 表示。

3. **什么是 Leitungscodierung？**  
   线路编码是把 bit 序列映射为物理信号元素。

4. **Manchester Codierung 的特点是什么？**  
   通过信号跳变同时表达数据和同步信息。

5. **有哪些 Trägermodulationsarten？**  
   常见调制方式包括振幅、频率、相位以及组合调制。

6. **介质有哪些重要属性？**  
   带宽、衰减、噪声、传播速度、误码率、成本和抗干扰能力。

## 四十、本章总览

第五章从 Internet 分层模型的底部出发，讲了从网络接入层到物理层的一整条链路：

1. 网络层把 packet 交给网络接入层，并提供 next hop。
2. 数据链路层用 MAC 地址在本地网络中寻址。
3. ARP 把 IP 地址解析为本地 MAC 地址。
4. 共享介质需要多路访问控制。
5. Aloha、CSMA/CD、MACA 分别体现不同的共享介质访问思想。
6. Switch 通过 MAC 表进行二层转发，减少共享介质冲突。
7. VLAN 在物理 LAN 上构造逻辑 LAN。
8. Parität、CRC、Hammingabstand 用于错误检测和部分错误纠正。
9. Ethernet 定义了重要的链路层帧格式和局域网机制。
10. 物理层负责 bit 到信号的转换，涉及采样、编码、调制和传输介质。

本章的核心联系可以概括为：

**IP 分组要经过下一跳，必须封装成二层帧；二层帧要真正传输，必须变成物理信号。**

因此，第五章补上了从“网络层路径选择”到“电信号/光信号实际传输”之间的关键部分。
