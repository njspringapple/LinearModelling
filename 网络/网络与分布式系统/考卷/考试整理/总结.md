## 2. 相关公式汇总 / Formeln

### 2.1 CSMA/CD 最大线路长度

$d_{max} = \frac{t_{frame} \times v}{2}$

其中：

- $t_{frame} = \frac{L \times 8}{R}​$（帧传输时间）
- L = 帧长度（字节）
- R = 传输速率（bit/s）
- v = 信号传播速度（通常 $2 \times 10^8$ m/s）

### 2.2 流量强度（Traffic Intensity）

$I = \frac{a \times L}{R}$

其中：

- a = 数据包到达率（packets/s）
- L = 数据包长度（bits）
- R = 链路带宽（bit/s）
- 当 I < 1 时系统稳定，I≥1 时会丢包

### 2.3 子网计算

子网数量=2(新前缀长度−原前缀长度)\text{子网数量} = 2^{(\text{新前缀长度} - \text{原前缀长度})}子网数量=2(新前缀长度−原前缀长度)

$\text{主机数量} = 2^{(32 - \text{前缀长度})} - 2$

$\text{多播地址数量}(224.0.0.0/4) = 2^{28}$

### 2.4 汉明距离与错误检测/纠正

 $\text{检测位错误: } H(C) \geq d + 1$

$\text{纠正 } d \text{ 位错误: } H(C) \geq 2d + 1$

### 2.5 IP分片计算

$\text{每片最大数据} = MTU - 20$

$\text{分片数量} = \lceil \frac{\text{原数据长度}}{\text{每片最大数据}} \rceil$

### 2.6 ISDN速率

$64 \text{ kbit/s} = 8000 \text{ samples/s} \times 8 \text{ bit/sample}$

### 2.7 协议栈开销计算

$\text{总长度} = \text{用户数据} + \text{TCP头(20B)} + \text{IP头(20B)} + \text{其他协议头}$

### 2.8 ATM封装

$\text{ATM信元数} = \lceil \frac{\text{数据长度}}{48} \rceil$

$\text{ATM总字节} = \text{信元数} \times 53$

### 2.9 比特率与波特率

$\text{Bitrate} = \text{Baudrate} \times \log_2(\text{符号数量})$

### 2.10 Shannon-Nyquist采样定理

$f_{Abtast} \geq 2 \times f_{max}$​

## 4. 易错点和关键点提示 / Häufige Fehler und wichtige Hinweise

### 4.1 概念混淆

|易混淆概念|区别|
|---|---|
|**流量控制 vs 拥塞控制**|流量控制保护接收方，拥塞控制保护网络|
|**TCP Tahoe vs Reno**|Tahoe: 超时和3个重复ACK都cwnd=1；Reno: 3个重复ACK进入快速恢复|
|**Switch vs Router**|Switch工作在L2用MAC，Router工作在L3用IP|
|**Hub vs Switch**|Hub共享冲突域，Switch隔离冲突域|
|**传输延迟 vs 传播延迟**|传输=数据推上链路，传播=信号在介质中传播|

### 4.2 计算易错点

**CSMA/CD计算：**

- 是**往返时间**，所以除以2：2×tprop≤tframe2 \times t_{prop} \leq t_{frame}2×tprop​≤tframe​
- 单位换算：帧长度要乘以8转为bit

**IP分片：**

- 数据必须是**8字节的倍数**
- 每个分片都有20字节IP头
- MF=1表示后面还有分片，最后一个MF=0但offset>0

**子网计算：**

- 子网掩码转前缀长度：数1的个数
- 255.255.255.192 = /26
- 255.255.255.128 = /25

**CRC计算：**

- 添加(n-1)个0，n是生成多项式的位数
- XOR除法，不是真正的除法
- 余数为0表示正确

### 4.3 关键记忆点

**IPv4头部包含：** 源IP、目标IP、TTL、协议字段、校验和等  
**IPv4头部不包含：** 端口号（在TCP/UDP头部）

**TCP头部包含：** 源端口、目标端口、序列号、确认号、窗口大小  
**UDP头部：** 只有8字节（源端口、目标端口、长度、校验和）

**端口号：**

- DNS: 53
- HTTP: 80
- HTTPS: 443
- SMTP: 25
- FTP: 20/21

## 5. 背诵点 / Zu merken

### 5.1 OSI七层模型（从下到上）

```
1. 物理层 (Physical) - 比特传输
2. 数据链路层 (Data Link) - 帧、MAC地址、错误检测
3. 网络层 (Network) - IP、路由
4. 传输层 (Transport) - TCP/UDP、端口
5. 会话层 (Session) - 会话管理
6. 表示层 (Presentation) - 数据格式转换
7. 应用层 (Application) - HTTP、DNS、SMTP
```

### 5.2 TCP拥塞控制四阶段

```
1. Slow Start - cwnd指数增长，直到ssthresh
2. Congestion Avoidance - cwnd线性增长
3. Fast Retransmit - 3个重复ACK后立即重传
4. Fast Recovery - ssthresh=cwnd/2, cwnd=ssthresh+3
```

### 5.3 TCP超时处理（Tahoe）

```
ssthresh = cwnd / 2
cwnd = 1
重新进入Slow Start
```

### 5.4 三次握手

```
Client → Server: SYN
Server → Client: SYN + ACK
Client → Server: ACK
```

### 5.5 四次挥手

```
A → B: FIN
B → A: ACK
B → A: FIN
A → B: ACK
```

### 5.6 常用协议端口


## 6. 计算套路总结 / Berechnungsroutinen

### 6.1 CSMA/CD最大距离计算

**步骤：**

1. 计算帧传输时间：$t_{frame} = \frac{L \times 8}{R}$​
2. 计算最大传播时间：$t_{prop} = \frac{t_{frame}}{2}$​
3. 计算最大距离：$d_{max} = t_{prop} \times v$

**例题：** 帧长64B，传输率10⁷ bit/s，传播速度2×10⁸ m/s

```
t_frame = (64 × 8) / 10^7 = 51.2 μs
t_prop = 51.2 / 2 = 25.6 μs
d_max = 25.6 × 10^-6 × 2 × 10^8 = 5120 m = 5.12 km
```

### 6.2 IP分片计算

**步骤：**

1. 计算每片最大数据：MTU - 20（向下取整到8的倍数）
2. 计算分片数量：⌈原数据/每片数据⌉
3. 画出各分片（记住每片都有20B头部）

**例题：** MTU=280B，原数据600B

```
每片最大数据 = 280 - 20 = 260 → 向下取整到8的倍数 = 256B
分片数 = ⌈600/256⌉ = 3
分片1: 头部20B + 数据256B
分片2: 头部20B + 数据256B
分片3: 头部20B + 数据88B (600-256-256=88)
```

### 6.3 子网计算

**步骤：**

1. 确定原前缀长度和新前缀长度
2. 子网数 = 2^(新-原)
3. 每子网主机数 = 2^(32-新) - 2

**例题：** 141.84.0.0/16用255.255.255.192划分

```
原: /16
新: 255.255.255.192 = /26
子网数 = 2^(26-16) = 2^10 = 1024
```

### 6.4 广播地址计算

**步骤：**

1. 确定网络部分位数
2. 将主机部分全置1
3. 转换回十进制

**例题：** 141.84.32.0/19的广播地址

```
/19 = 前19位是网络部分
141.84.32.0 = 10001101.01010100.001|00000.00000000
将主机部分(后13位)全置1:
10001101.01010100.001|11111.11111111 = 141.84.63.255
```

### 6.5 CRC计算

**步骤：**

1. 生成多项式转二进制（从最高次到常数项）
2. 原消息后添加(n-1)个0
3. XOR除法
4. 余数附加到原消息

**例题：** 消息110011，G = x³ + x + 1 = 1011

```
110011 + 000 = 110011000
XOR除法:
110011000 ÷ 1011
...（详细除法过程）
余数 = 011
传输: 110011011
```

### 6.6 协议栈开销计算

**步骤：**

1. 从上到下逐层添加头部
2. 注意ATM的48B负载和53B信元

**例题：** TCP 438B用户数据通过ADSL发送

```
TCP: 438 + 20 = 458B
IP: 458 + 20 = 478B
PPP: 478 + 5 = 483B
ETH: 483 + 14 + 4 = 501B
ATM信元数: ⌈501/48⌉ = 11
ATM总字节: 11 × 53 = 583B
```

### 6.7 TCP窗口/序列号计算

**规则：**

- 序列号 = 已发送字节数
- 确认号 = 期望收到的下一个字节号
- SYN和FIN各占1个序列号
- 窗口 = 剩余缓冲区大小

**例题：** 发送1024B，初始Seq=0，缓冲区4096B

```
发送后: Seq=0, 数据1024B
ACK: ACK=1024 (期望下一个字节)
Win: 4096-1024=3072B
```
